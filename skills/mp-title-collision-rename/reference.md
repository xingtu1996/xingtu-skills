## 一、首案全记录（AGENT-03，2026-09-15 实测）

**旧题**：《AI Agent 三国杀：WorkBuddy、豆包工作、千问办公怎么选》

**撞题核查（双查取并集，实测 ≥10 篇同题、含四家大媒体）**：

| 来源 | 标题（同题证据） |
|---|---|
| 腾讯新闻 09-09 | 豆包工作、千问办公、WorkBuddy的AI办公"三国杀"（**几乎一字不差，只换词序**） |
| 虎嗅 / 网易 / 澎湃 | 同题转载或同题原创各一篇 |
| 澎湃（另两篇） | AI Agent"三国杀"：字节抢跑、阿里突围、腾讯蓄势；国产AI御三家掀办公Agent三国杀 |
| 掘金 / segmentfault / CSDN / 知乎 / 头条 | 各一篇「三家 + 三国杀 + 怎么选/横评」 |

判定 🔴 → 换题。诊断要点：**同题竞争下小号的死法是搜一搜被大媒体淹没 + 原创审核多一层摩擦 + 独有论点被俗框架词埋没**（该案真正独有的四点——按生态选、老板视角、月活第二没写进来、选完之后的空位——全被"三国杀"壳子盖住）。

**三候选与拍板**：

| 候选 | 标题 | 权衡 |
|---|---|---|
| A 老板视角版（**boss 选定**） | 员工比功能，老板看生态：WorkBuddy、豆包工作、千问办公选型账本 | 钩子进前 15 字（列表页可见）+ 三产品名吃长尾 + 与封面副标一致 + 命中管理层定位 |
| B 反常识悬念版 | 没有谁更好：WorkBuddy、豆包工作、千问办公的选型只看一件事 | 更挑点击、悬念强，但老板视角弱一档 |
| C 榜单反差版 | 月活第二的百度搭子没进这篇选型：办公 Agent 按生态选，不按排名 | 最独特、最不可能撞题，**但丢三个产品名搜索词**，搜一搜活路变窄 |

**新摘要**（≤120 字，三条病都清）：「同一款工具，在飞书公司和钉钉公司手里是两种命运。这篇不比功能清单，比三家各自绑定的生态，以及老板掏钱前该问的三件事。文末留了个空位：选完之后，谁帮你把两层走通。」
旧摘要三病：与标题重复度高 / 三论点挤一句 / 「生态决定八成体验」的"八成"像事实陈述但其实是作者判断。

**六载体实测计数**（改前 `grep -c` 得到，直接写进 assert）：正文 `01_正文/正文_v5.md` 旧标题 **3 处**；`00_标题摘要/标题摘要.md` 标题 2 处 + 摘要 1 处；`05_合集/合集规划与选题卡.md` 1 处；`04_配图/00-引子图-三家生态位.html` 主标 1 处；`03_封面/封面_V2_官方图标白.html` 1 处；`02_排版HTML/公众号_发布版.html` 重渲得到。内文"三国杀"比喻**保留 2 处**。引子图主标改成与标题解耦的判断句「选型的真正棋盘」。

**封面自抓两缺陷**：① 主标 12 字 @46px 超宽，断出孤字「态」→ 降 38px；② `title2` 残留旧 `<span class="em">老板看生态</span>`，与三家名拼成「…千问办公老板看生态」→ 删除（第一次按 `class="hl"` 替换不中，grep 后才知道是 `em`）。

**收口**：dry-run 嵌图 9/9 → 建稿 → `draft/get` 回查（错名 0 / 旧标题残留 0 / 封面逐字节一致 / 评测风）→ 回收 00:15 旧标题稿 → 认 01:00 那份 → 操作单表驱动同步（认稿时间 + `media_id` + 标题）。

## 三、封面主标字号-字数对照（900px 版式，PUB-045 家族配色）

| 主标字数 | 起始字号 | 说明 |
|---|---|---|
| ≤9 字 | 46px | 实测安全 |
| 10–13 字 | 38px | 46px 下 12 字已实测溢出断孤字 |
| >13 字 | ≤32px 或改两行结构 | 两行时**必须每行成句**，禁孤字行 |

判定不靠算，靠眼：改完必 `fig_fit.py` 重渲 → **Read PNG** 看是否单行、有无孤字、有无残留 span、logo 与底牌齐全。深浅底交替去查发布日志最近一篇，不信包内旧备注。

## 四、候选生成四问（写候选时逐条自问）

1. 钩子是否落在**前 13–15 字**内？（列表页截断位，超了等于没有钩子）
2. 专有名词/英文缩写是否 **≤2 个**？超了正文首段有没有人话解释？
3. 是否命中**具体数字 / 读者痛点 / 冲突反差 / 反常识判断**四选一？
4. 有没有把正文**最独特的那个判断**提到台面上？（壳新不新不重要，独有论点被埋没才是最大损失）

四问有一问过不了 → 迭代候选，别急着交 boss（PUB-023：没打磨到「特别好」不往外放）。
