# xingtu-role-audit · AI 头衔定位自查

把文章《AI Native 时代，你想成为哪种工程师？》里的「三数自查」变成可执行工具：
对一个 AI 工程化项目跑一遍，量出三数，出可视化报告，告诉你**你现在在哪一格、往哪走**。

## 背景（为什么信这个框架）

- 头衔（Vibe Coder / AI Native / Harness / Agentic / Builder / FDE）定义不可证伪，谁都能对号入座。
- 可测的是三个数：**自治度**（你给 Agent 多大自主权）、**护栏密度**（harness 常驻注入多大）、**边际收益**（护栏继续加还有没有正收益）。
- 这套判据来自行途的一线实践（harness 减法 8.5x→1.09x 打脸教训：数字会骗人，量纲对齐 + 审计）。

## 快速开始

```bash
python3 ~/.workbuddy/skills/xingtu-role-audit/scripts/audit.py --dir ~/projects/<COMPANY_GITLAB>
```

输出：`<项目目录>/ai_role_audit_report.html`（自包含 HTML，可截图分享）。

参数：
| 参数 | 说明 |
|------|------|
| `--dir` | 目标项目（扫其 `.claude/` / `.workbuddy/` 常驻 md 估护栏密度） |
| `--sessions-dir` | Claude Code 会话根目录（默认 `~/.claude/projects`），采样最近会话估介入率 |
| `--out` | 报告输出路径（默认项目目录下） |

## 三数口径（诚实标注，绝不装精确）

| 数 | 自动测法 | 口径 | 可信度 |
|----|---------|------|--------|
| 护栏密度 | 扫 `.claude`/`.workbuddy` 下 md 累计字符 | `字符数/1.8 ≈ token`，预算 50K（1M 窗口 5% 规则） | 中（估算） |
| 自治度 | 采样最近 1 个会话 jsonl，数人工文本介入 / (工具调用+人工) | 介入率 = 需要人点头的比例 | 中低（采样，格式多样） |
| 边际收益 | 读项目下 `harness-audit.json`/`audit_before.json` 前后对照 | 无记录则引导做减法 | 依赖人工 |

**测不到的绝不编**：会话读不到 → 报告标注"未自动测出，请自评"；边际没做实验 → 报告给减法引导。

## 前进方向（内置规则，三数映射行动）

- 护栏 > 50K → 做减法，砍到最小有效集（逐个 hook 审计）
- 介入率 > 60% → 点头太多：能 Bash 就不 Agent，任务整包下发
- 介入率 < 25% → 自治放得开：补护栏/验证脚本，别裸奔
- 边际实验后无正收益 → 砍该护栏
- 两轴象限落位：高自治高护栏=Agentic 目标区｜高自治低护栏=Vibe 危险区｜低自治高护栏=Harness 护栏过剩区｜中中=AI Native 过渡区

## 输出物

- 终端一行摘要（三数 + 定位）
- `ai_role_audit_report.html`：定位卡 + 象限 SVG（你的坐标点）+ 三数明细 + 前进方向清单
