# Free Token Channel Audit — 免费渠道周期审计

## 判断准则：什么进本 skill，什么不进

- ✅ 有时效的渠道状态（限时免费/新人包/滚动免费池）→ 每次复查
- ✅ 隐私分级与使用路线 → 结论复用，个别渠道条款变了才更新
- ❌ 一次性申领动作（注册建 Key）→ 不入 skill，走清单 checklist
- ❌ 一次性架构决策（如 Cherry Studio 摆位）→ 记进工作区记忆，不进 skill

## 复查 SOP（每次触发按序执行）

1. **翻时效台账**（下方「当前时效表」），列出 30 天内到期/已到期的项 → 标警报。
2. **逐渠道验证**（并行 WebSearch，freshness 限近 3 个月）：
   - 免费政策是否延续/改版（重点：积分制系数、冻结金额、隐私条款）；
   - 速率限制是否变化（RPM/TPM/RPD）；
   - 新渠道扫描：搜「免费 token 白嫖 <当月>」类实测文章，只采信有实测数字的。
3. **本机资产盘点**（本地命令，零成本）：
   - `ls ~/.ollama/models/manifests/registry.ollama.ai/library/`（本地模型在位情况）
   - 元宝素材卡数量（`素材库/materials_library.json`）——零 token 路线的库存。
4. **重新分级**：按隐私四层（体验级/生产绿区/灰区/红区）套每个渠道，红区永远只有本地。
5. **产出**：更新《免费token渠道作战清单》HTML（v 号 +1），时效变更项加警报；回写 CHANGELOG。
