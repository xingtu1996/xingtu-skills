# 多平台分发流水线（xingtu-multiplatform-distribution）

> **适用范围守卫**：专为「行途」工作区设计（依赖 `outputs/发布包_*/`、`specs/20260909-多平台铺开与自动分发流水线/`、PUB-004/020 红线）。当前工作区无这些结构时（如公司侧仓），声明不适用并停止。
> 分工边界：**本技能生成变体物料 + 操作单 + 排产表**；发布由 boss 逐平台点执行（现阶段无自动发布通道，抖音/小红书为手机端）；公众号群推话术走 `mp-group-push-copy`；发前核验走 `mp-prepublish-draft-verify`。

## 底座（先读，SSoT 不复制）

1. **平台规格卡 SSoT**：`specs/20260909-多平台铺开与自动分发流水线/`（9/9 规格卡契约）。最近实例的执行版规格：`outputs/发布包_2026-09/多平台分发/FDE国家点名文_20260915/00_规格卡与发布操作单.md`
2. **成品包格式基准**：`outputs/发布包_2026-09/多平台分发_MODEL-02_20260915/`（00_README 规格表 + 01~06 各平台变体 + 07 backlog + 08 图卡）
3. **图卡脚本先例**：`多平台分发_demo_B16_20260914/06_图卡生成/gen_b16_cards.py`；渲染用 `tools/fig_fit.py`
4. **钩子定义**：「可转述的反常识点」判据与提炼法**引用** `mp-group-push-copy` Step 3，本文件不重复定义。

## 七步流程

### Step 1 · 时序闸门（硬性，先过再动笔）

- 母稿必须**公众号已实际发布**（草稿不算），声明原创稿首发前全文禁上任何公网站点（铁律 9）。
- 各平台外发时序按规格卡：技术长文类（掘金/CSDN）**首发 +24h**，问答/图文类（知乎/小红书/抖音）**+48h**；X 不受微信额度限制可随时。
- **一天最多铺 2 个平台**，同源平台（掘金/CSDN）之间错开 ≥12h，防被识别同源铺量。

### Step 2 · 定位母稿与物料缺口

读发布包 `01_正文/` 最新终稿 + `03_封面/` + `04_配图/`，对照本包目标平台清单，列「已有 / 待产出」物料表。

### Step 3 · 定钩子与各平台切面

复用母稿的反常识点，按平台用户语境定**每平台的切入问题**（知乎=找 3~5 个真实问题各写一篇回答；小红书=一图一观点拆 6~9 卡；抖音=前 3 行重写口播钩子）。钩子不换，切法必换。

### Step 4 · 逐平台写变体（反通稿闸门）

按规格卡逐平台改写，**结构级差异 ≥30%**（标题策略/篇幅/组织方式/收尾都不同），非删段复制：

| 平台 | 形态 | 关键改造 | 外链口径 |
|---|---|---|---|
| 掘金 | 技术长文 | SEO 埋词、结论前置为独立节（写「先说结论」，不用 TL;DR 这类英文黑话）、工程结构、结尾只留署名段 | 可带公众号原文（以规格卡为准） |
| 知乎 | 问题回答体 | 借问题切入、第一人称、克制软引导（同平台多篇不复用同图，防铺量痕迹） | 禁硬链，文末软引导 |
| CSDN | 步骤教程 | 标题含实操词、步骤化（分类/标签走后台字段，不写进正文） | 走推广卡/允许位 |
| 小红书 | 图文笔记 | 标题≤20字、口语钩子、话题标签、5~9 图卡 | 禁外链二维码，主页承接 |
| 抖音 | 口播+图文轮播 | 前3行钩重写、分镜、隐私隔离 | 不硬链 |
| X | Thread 4~5 条 | 每条一个数字、末条收口 | 简介挂品牌号 |

**变体去 AI 味（检测器优先，写完必过）**：每份变体落笔后 `python3 tools/de_ai_flavor_check.py <变体.md>` 先拿客观命中清单（不凭手感）——加粗 ≤8 是硬指标（FB-C-050：只保最吃重的数字/判断加粗，「**标签**/**互动收尾**/**关于作者**」这类**结构性加粗一律脱掉**）、拆超长段、清 AI 腔词；复检退出码 0 才算定稿。**改完必须据新稿重出「富文本内嵌图 HTML」**（图已按 5b 内嵌，不再有单独的插图占位版），防旧版带病交付（母稿过了门禁不代表变体过，MODEL-02 掘金版实测首扫加粗 25 处）。

### Step 5 · 图卡生成与富文本交付

**5a · card 模式（小红书/抖音需要时）**：写 `08_图卡/cardN.html`（3:4、1080×1440@2x、与账号视觉体系一致，一图一观点）→ `python3 tools/fig_fit.py <html> --width 1080 --bg <底色>` 渲 PNG → **逐张 Read 看图**（文字溢出/截断/错字）后才算就绪。风格参考既有 `多平台分发_MODEL-02_20260915/08_图卡/`。

**5b · 配图内嵌 + 富文本内嵌图 HTML（掘金/CSDN/知乎等富文本编辑器平台）**（2026-09-16 boss 复核 MODEL-02 掘金稿后重写口径）：
1. **母稿 `04_配图/` 的非表格信息图（引子转录卡 / 数字卡 / 清单卡 / 真实账单图）必须直接内嵌进变体 MD**，写**本地绝对路径** `![图名](/Users/.../04_配图/xx.png)`，放在它所支撑的那段之后；**不写「📷 上传位」这类内部备注**——读者可见文本里不留工单语言，图与位置的对应关系由本包 README 操作单承载。
2. **表格保留原生 markdown 表**：掘金/CSDN/知乎表格渲染正常且能被平台搜索收录，图化＝同屏两份重复。**只有公众号**因编辑器列宽错乱才走 PUB-054 表格图化，别把公众号那套搬过来。母稿的「目录清单图」不搬进变体：它画的是母稿节结构，变体节数不同＝图文矛盾，且常含私域表述（"群里问得最多的三个问题"类）。
3. **本地路径只用于本地预览**：掘金/知乎**不上传本地路径图片**，粘贴后必须**先删掉 `![...](/Users/...)` 图片行**，再在原位拖入 PNG（平台自动传 CDN 换链接）。留着＝线上破图 + `src` 暴露本机账号名。操作单要把这条写成显式步骤（2b/3b/4b），别指望 boss 自己想到。
4. **富文本内嵌图 HTML**：`python3 tools/md2html.py <变体.md> <平台>_富文本_内嵌图.html`（v1.1 自动把本地 `![]()` 转 base64，单文件零外链）→ 双击即预览图文位置；复制进编辑器后个别图没跟过去，按操作单手动拖入。生成后 grep 一遍 HTML 内 `/Users` 应为 0（防本机路径渗进公开件）。
> 口径钉死：**掘金无开放草稿 API**（不像公众号可走 API 建稿），只能浏览器驱动且需登录+过风控 → 维持「半自动·复制即发」，**不为它现建 Playwright**——除非 boss 明确点头。

### Step 6 · 发布操作单 + 排产表 + 红线自检

包内写 `00_README.md`（规格表 + 物料清单 + 建议时序）与逐平台操作步骤（登录入口→粘贴哪个文件→分类/标签→头图→外链动作→发布→**回填链接**）。发布前逐平台红线自检：

- [ ] `python3 tools/privacy_scan.py --fail-fast` 全绿（变体也要过，SAF-004/010：无真名/公司名/薪资）
- [ ] 每份变体 `de_ai_flavor_check` 复检通过（退出码 0，贴复检输出行；见 Step 4 子步）
- [ ] 非通稿：与本包其他变体和母稿有结构级差异
- [ ] 数据带来源、小节指代回母稿核对
- [ ] 无公众号内部预告/合集列表外泄（PUB-049）
- [ ] 无源私域场景（"连麦/内部朋友说"类，B-009）
- [ ] **正文零工单语言**：顶部「版本：…｜母稿…已首发（+24h 窗口已过）」「外链口径（主索引 SSoT）」、文末「标签：」「分类标签：」「📷 上传位」一律移出正文，交 `00_README` 承载（2026-09-16 boss 复核：这些是给执行人看的，不是给读者看的）
- [ ] **零黑话、零编造互动**：`TL;DR` 等英文缩写改中文节名；不写"评论区贴个量级我帮你估算收益"这类替 boss 承诺答疑的收尾（与群推话术「禁编造社交事实」同源红线）
- [ ] **配图已内嵌**：变体 MD 内 `![](/Users/...)` 数 = README 操作单列出的图数，且每张图路径 `-f` 可达；HTML 预览件已随新稿重出

### Step 7 · 落盘与收口

- 包结构：`outputs/发布包_YYYY-MM/多平台分发_<母稿名>_<YYYYMMDD>/`，内含 `00_README / 01_掘金版 … 06_X版 / 07_backlog / 08_图卡/`（沿用 MODEL-02 包惯例）。
- `changelog_append.py --tool qwenwork` 回写 + `产出索引.md` 登记。
- **留痕纪律（命令化闭环）**：每平台发布后 boss 给截图 → 一条命令登记：`python3 tools/evidence_register.py --register <截图路径> --platform <平台> --date <实际发出日>`（自动识别平台、按**发出日而非截图日**改名 `分发凭证_<平台>_<日期>` 移入投放口 `outputs/多平台分发/`、现跑 `dispatch_feed.py` 打印闭环率前→后、ls 落盘自证；补登旧发布务必显式给 `--date`；闭环率公式 SSoT 在 `tools/dispatch_feed.py` 与 `data/dispatch_config.json`，本 skill 只引用一条命令不复制算法，登记细节见 `mp-distribution-evidence-loop`）。README 物料表状态列回填（待发布→已发布+链接）与台账更新照旧，两者不互替。物料交付 ≠ 分发完成；分发凭证为零是当前矩阵最大缺口，本 skill 的存在就是为了补上这条证据链。

## Pitfalls（实测坑）

- **换标题不换结构** = 通稿，PUB-004 红线 + 平台查重限流双杀。判据：遮住标题读三段，认不出是母稿的姐妹篇就合格。
- **时序没算**：原创首发前把全文变体铺到公网站点 = 破原创（铁律 9）；+24/48h 从**实际发布时间**起算，不是定时设定时间。
- **图卡渲完不看图**：HTML 溢出/字截断肉眼不可见于代码，必须 Read PNG 逐张验（本轮 fig_fit 后看图已是惯例）。
- **外链口径想当然**：各平台"可带/禁导流/推广卡"以规格卡为 SSoT，平台政策会变，每次发布包重读一遍，不凭记忆。
- **账号状态没核**：掘金/知乎/CSDN 品牌化、小红书/抖音更名激活是否就位——发布前查 `多平台分发/00_账号就位确认清单.md` 与最近凭证目录，缺了先报告，不发在裸号上。
- **只交物料不收凭证**：没有回填链接的包 = 下轮还是黑盒。
- **把公众号排版律当全平台律**：PUB-054 表格图化、首屏公式、目录清单图是**公众号专属**（编辑器会搞坏表格 + 手机窄屏需要目录图）。掘金/CSDN/知乎照搬＝表格重复两份 + 图文节数对不上（MODEL-02 09-16 首案被 boss 抓出）。
- **本地图片路径当上传**：md 里的 `/Users/...` 只是给本地预览看的，平台不会替你传 CDN，直接贴上去就是破图 + 泄漏本机账号名（见 Step 5b 第 3 条）。
- **只交裸 markdown 不出富文本内嵌图 HTML**：掘金等富文本编辑器下裸 md 表格/图片全塌，boss 粘贴即劝退。表格重型平台必须按 Step 5b 出「插图占位 MD + 内嵌图 HTML」双版。
- **变体没过去味检测 = 只完成一半**：母稿过了 PUB-027 不代表变体过——变体改写时加粗会越写越多（MODEL-02 掘金版首扫 25 处 >8），必须每变体单独跑 `de_ai_flavor_check` 复检，且改完据 v2 重出下游产物。

## Verification（成功凭证）

- 包目录存在且含 `00_README.md`（规格表+物料清单+时序+卡点）与各目标平台变体文件；
- 每份变体与母稿 diff 后结构级差异明显（抽查标题、首段、小节组织三点）；
- 图卡（如产出）全部渲染并逐张 Read 通过，`08_图卡/` PNG 数 = README 物料表数；
- 时序闸门有留痕：README 中写明母稿实际发布时间与各平台最早发布时间；
- `privacy_scan --fail-fast` 全绿凭证（贴退出码/输出行）；
- 每份变体 `de_ai_flavor_check` 复检退出码 0（贴输出行，加粗 ≤8 等硬指标达成）；
- 富文本平台（掘金/CSDN）有「插图占位版 MD + `md2html` 内嵌图 HTML」双产物，HTML 体积 ≈ 内嵌图卡规模（MB 级，说明图真进了单文件）；
- 发布后凭证登记：`evidence_register.py --register` 输出的闭环率前→后打印行 + 投放口 `ls` 可见 `分发凭证_<平台>_<日期>` = 回填凭证；
- CHANGELOG 回写 + 产出索引登记 = 完成判定；已向 boss 明示"发布后逐平台截图回填，才算这一轮分发有凭证"。
