## 二、分发铁律（SSoT = 发布日历 §三条 + SOP）

1. **公众号全网首发**（PUB-003）：外站不得早于公众号。
2. **闸门 ≥24h**：公众号首发后 ≥24h 才铺外站。
3. **同源错峰 ≥12h**：同篇内容在不同外站间隔 ≥12h，一天 ≤2 平台。
4. **差异化改写**：30–35% 结构级变体，标原创，禁通稿（PUB-004）。
5. **API 限制**：个人号 API 仅到草稿箱/预填，群发与外站点发布 boss 人工。
6. **红线 SAF-010**：不露雇主 / 不用真名 / 不用 行途；小红书·抖音禁外链、掘金禁引流、知乎禁导流。

## 三、工具接口签名

### `tools/evidence_register.py`（凭证登记 + 闭环率刷新）
```
--register <截图路径>         发布后截图（文件或目录，任意命名/位置）
--platform <平台名>           缺省时从文件名/目录名自动识别
--date <YYYY-MM-DD>          实际发出日（补登旧发布务必显式给）
--dest <目录>                投放口（默认 outputs/多平台分发）
--feed-out <路径>            dispatch_feed 输出改道（自测防污染）
--no-feed                    只登记，不重算闭环率
--dry-run                    只打印将做什么，不动盘
--list                       只盘点 clean 凭证与闭环率
```
退出码：0 成功 / 2 参数或平台无法识别 / 3 落盘自证失败 / 4 dispatch_feed 重算失败。

### `tools/dispatch_feed.py`（晨间调度喂数器，闭环率 SSoT）
```
--date <YYYY-MM-DD>          默认今天
--out <路径>                 输出改道
```
只读三源：`素材库/materials_library.json` + `outputs/发布决策简报_*.json` + `data/manual_metrics.json`；
产出 `outputs/今日调度_<date>.json` + `.md`。闭环率公式 AC-6（已执行÷已给建议），凭证唯一化 AC-5。

### `scripts/inventory_matrix.py`（本 skill 附带，一键盘点）
```
--root <xingtu根>            默认 . （须在 xingtu 根运行）
```
只读扫描 `outputs/发布包_2026-09/_archive/已发布/` + `多平台分发*/分发凭证_*`；输出平台×文章表 + 闭环率缺口。

## 四、闭环率定义

- **分子（已执行输出）**：存在 `分发凭证_<平台>_<日期>.png` 的外站分发（脏前缀"品牌化/更名/认证/抖音隐私"排除，见 dispatch_feed AC-5）。
- **分母（已给建议）**：公众号已发 A/B 级 × 适配平台数（矩阵 SOP 建议分发总数）。
- **真值来源**：凭证文件本身，非台账文字（符合"完成判定查凭证"铁律）。
