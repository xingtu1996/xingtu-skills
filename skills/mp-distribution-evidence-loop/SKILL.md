# 分发闭环回填（mp-distribution-evidence-loop）

> **适用范围守卫**：专为「行途」工作区设计。先读根 `AGENTS.md`，确认含「行途」才继续；否则零业务文件读取、声明不适用并停止。
> **分工边界（只编排不复制）**：本技能管**发布之后的证据回填侧（写侧）**。分发前物料归 `xingtu-multiplatform-distribution`（上游）；日报展示闭环率归 `mp-daily-ops-report`（读侧）；群推话术归 `mp-group-push-copy`。**闭环率公式与脏凭证排除口径的唯一 SSoT 在 `tools/dispatch_feed.py` 与 `mp-daily-ops-report` §分发凭证唯一口径（AC-5），本文件引用不复制、不自定义算法。**

## 机制（已实测核实，写卡前先信这段）

- **闭环率 = 当日合规 `分发凭证_` 数 ÷ 当日建议数**（`dispatch_feed.py` 的 evidence/metrics 段计算）。
- 丢进一张合规命名凭证 → 重跑 `dispatch_feed` → 闭环率 +1。这是**唯一**能转动闭环率的输入动作。
- 脏前缀 `凭证_*`（账号品牌化/认证/隐私截图）**自动排除不计**——旧 glob 曾把它们假计成分发（实测脏计 9 项），故命名前缀是硬闸门。
- 次日 09:30 定时日报会自动重算；手动回填不必等定时。

## 两种执行模式

### Mode A · 代回填（默认，boss 丢截图给 agent 时）

1. **收图**：boss 发来一张或多张"已发出"截图（公众号群发成功页 / 掘金 / CSDN / 知乎等发布成功页）。
2. **判平台与日期**：从截图内容识别平台；**日期 = 实际发出日**（不是截图/回填当天——跨日回填时以发出日为准，不确定就问 boss 一句）。
3. **归档**：复制到 `outputs/多平台分发/`，命名 `分发凭证_<平台>_<日期>.png`，例：
   - `分发凭证_掘金_2026-09-17.png`
   - `分发凭证_公众号群发_2026-09-17.png`
   - 同平台同日多张 = 只留一张最完整的（一图含链接/标题/时间），多余的不丢进投放口。
4. **现跑重算**：`python3 tools/dispatch_feed.py --date <目标日>`（多日凭证则各跑各的日期）。
5. **报数验证**：从输出（或 `outputs/今日调度_<date>.json` 的 evidence 段）读闭环率，向 boss 报 before→after。**认磁盘**：`ls outputs/多平台分发/分发凭证_*` 计数与 feed 输出一致才算完成，不信"应该已更新"。

### Mode B · 自助指引（boss 问"怎么弄/傻瓜办法"时）

直接给以下三步卡（与 spec `07_傻瓜闭环操作卡.md` 同源，那边过期以本技能为准并回写那边）：

> **看** → 09:30 微信《四块晨间决策》只看 ①：主推开哪篇、今天铺哪个平台。
> **发**（人工）→ 公众号后台群发主推 + 按 ①/② 铺 1 个平台（一天 ≤2 平台）。
> **回填** → 截图丢 `outputs/多平台分发/`，命名 `分发凭证_<平台>_<日期>.png`，再跑：
> `python3 tools/dispatch_feed.py --date <目标日>`（或次日 09:30 自动重算）
> **怎么知道转起来了** → 日报③ `闭环率` 不再 = 0。

## Pitfalls（红线，会白干）

1. **群发/铺平台永远人工**：系统只出决策和话术，绝不代发、绝不自动群发（个人订阅号群发 API 已回收）。本技能收到再多的"帮我发"也只做到草稿箱可发状态（交棒 `mp-publish-sop`），凭证环节只认**已发出**的截图。
2. **数据 T+1**：今天发的，明天数据才进快照。别当天盯着"外站没涨"就重发或误判失败。
3. **脏截图别进投放口**：`凭证_品牌化/认证/隐私…` 是账号设置截图，命名不带 `分发凭证_` 前缀即自动不计——但别主动把它们往 `outputs/多平台分发/` 丢，保持投放口纯净。
4. **只回填凭证，不越界**：不改稿、不发布、不回填台账以外的任何状态；台账/物料表回填链接是 `xingtu-multiplatform-distribution` 的纪律，两边各管各的落点。
5. **口径漂移防线**：若 `dispatch_feed.py` 改了命名/目录/公式，先改 SSoT 再回写本技能，不在本文件另起一套判定。

## 留痕

- 单张凭证回填**不**逐条写 CHANGELOG（凭证文件本身即磁盘证据）。
- **批量回填**（≥3 张）或**改动投放口结构/命名约定**时，回写 CHANGELOG：
  `python3 tools/changelog_append.py --type "🔧" --path "outputs/多平台分发/" --desc "<回填了哪几天几平台凭证/改了什么约定>" --tool <本工具身份>`

## Verification（成功凭证）

- `ls outputs/多平台分发/分发凭证_*` 新增文件数 = 本次回填数；
- `dispatch_feed.py` 本轮输出中 evidence/闭环率数值相应 +N（与文件计数一致）；
- 向 boss 报出的数字来自本轮实跑输出，非记忆或推测。
