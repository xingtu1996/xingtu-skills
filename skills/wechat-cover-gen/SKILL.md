# 公众号封面生成（真人剪影路线）

> 2026-09-29 boss 拍板：封面要有**真人/可挖掘的点**，不要纯几何图形。纯 HTML 几何封面已证伪（FDE 爆分享封面是真人剪影）。
> 选型见 DESIGN.md §二·补三方向；本 skill 默认走方向②人物纪实背影（人设/观点/工程感），方法论长文可切③沙盘。

## 五步管线

1. **出场景图**（image_gen / seedream，2.35:1，约 2350×1000）：
   固定 prompt 骨架——
   > 电影感宽幅摄影，一个工程师的**背影剪影**站在[深色机房/黄昏窗边/控制台前]，面向[屏幕墙/夕阳]，**橙红色逆光从身后打出轮廓光**，整体几乎全黑只留人物轮廓和光点，不露正脸，胶片高对比，无任何文字，2.35:1 宽屏，**人物偏左，右侧留大量暗部负空间**。

   三原色锁死：黑 #1a1a1a / 白 #fff / 橙红 #F2644F，禁其他主色。

2. **下载**：`curl -sL -o scene.png <图URL>` 落到发布包 `03_封面/`。

3. **HTML 压字**（模板见同目录 `cover_template.html`）：
   - `body{width:900px;height:383px}`
   - 背景 `scene.png cover` + 从右到左加深的黑渐变遮罩（保证右侧文字可读）
   - 文字压**右侧暗部**：左上小 tag（合集名灰字）+ 主词（≤6字/行，白字，一个词用橙红 #F2644F 强调）+ 一行灰副标
   - **封面不复述标题**：只留 ≤1 主词，标题交给公众号原生标题栏

4. **渲染**：
   ```bash
   python3 tools/fig_fit.py <cover.html> --width 900 --bg "#1a1a1a" --out <封面名>.png
   ```

5. **验收（不可跳过）**：Read 亲眼看图——
   - 文字无孤字换行（字数×字号<470px）；
   - OCR 全对（AI 场景图无文字，字是 HTML 压的，不会错）；
   - 人物不露正脸；
   - 黑白底色与上一篇实发封面交替（查后台近期发表，不查包内旧备注）。

## 黑白律动
一篇黑底一篇白底交替。黑底=场景图偏暗+白字；白底方向另出浅色场景图。发完在台账记下本次用了哪个色。

## 落盘与同步
- PNG 落发布包 `03_封面/`；
- **封面=引子图同款**：首屏引子图复用同一张 PNG（DESIGN §二补 坑位67）；
- 改标题后必须重渲封面并 Read 复验。
