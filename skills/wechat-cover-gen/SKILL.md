> 2026-09-29 boss 拍板：封面要有**真人/可挖掘的点**，不要纯几何图形。纯 HTML 几何封面已证伪（FDE 爆分享封面是真人剪影）。
> 2026-10-12 boss ADV-02 拍板（v1.1.0）：新增路线 B **简笔画形象化**——AI 生图出简笔画人物/场景（一桌杠精、分裂小人），方式/形式/形象描述都对味，后续文章往这个方向靠拢。
> **🆕 2026-10-12（v1.2.0）boss 指令：「现在封面风格挺好的，可以封装 1 个 skills，后续封面可以尝试使用这个来进行配置生成封面」**——把封面生成升级为**配置单驱动**：每篇封面只需填一张配置单（构图类型 + 主词 + 底色 + 强调点），即可复用风格模板快速出图。

## 🔴 铁律（v1.2.0 起强制）

1. **AI 生图只出无文字构图**：prompt 骨架里必须带「无任何文字 / no text / no letters」。AI 中文生图目前仍会糊/错/繁简混（ADV-02「杠精→红娘」实锤），不要指望 AI 把字写对。
2. **正式封面文字一律 HTML 覆字渲染**：主标/副标/tag/footer 全部在 `cover_template.html` 里用 CSS 写，再 `fig_fit.py` 渲 PNG。改字改色重渲成本极低（改 HTML 一行即可）。
3. **封面不加「合集」标签**（boss 拍板，mp-publish-sop 坑位 59 强化）：合集后台已有，封面再放=画蛇添足。每次渲封面必 grep `.tag` 类合集字样，Read 回查 PNG 亲眼确认无 tag。
4. **OCR 回查不可跳过**：渲完 PNG 必须 Read 亲眼看——文字无错字、无孤字换行、人物不露正脸（路线 A）/简笔画风格统一（路线 B）、三原色锁死。
5. **封面=引子图同款**（坑位 67/72）：定稿后 `cp 封面.png → 04_配图/00-封面引子图.png`，改封面必须同步引子图。

## 〇、配置单驱动（v1.2.0 核心）

每篇封面开工前先填一张**封面配置单**（默认随发布包 00_README 或单独 `封面配置单.md` 落 03_封面/）：

```yaml
# 封面配置单
article: 文章代号（如 ADV-02）
title: 发布标题（公众号原生标题栏显示，封面不复述）
main_word: 封面主词（≤6字，1 个词可橙红强调；从标题提炼，非标题复述）
sub_line: 一行副标（可选，灰色，≤15字）
route: A 真人剪影 | B 简笔画形象
composition: 构图卡编号（见下方构图库）
bg: black | white（黑白律动，按排期表交替）
emphasis: 强调色点（默认 #F2644F 橙红，1-2 处）
note: 特殊要求（如：要有科技感网格/要机器/要记忆管理意象）
```

**出图流程**：读本 SKILL → 填配置单 → 按构图库拼 prompt → image_gen 出无文字构图 → curl 下载 → HTML 覆字 → fig_fit 渲染 → Read 验收 → 落包+同步引子图。

## 五步管线（双轨共用）

1. **出场景图**（image_gen / seedream，2.35:1，约 2350×1000）：
   - 从构图库选卡，拼 prompt：`极简黑白简笔画风格 + <卡片段> + 无任何文字 + 2.35:1 宽屏 + 构图偏左/居中，右侧/下方留负空间压主标`
   - 三原色锁死：黑 #1a1a1a / 白 #fff / 橙红 #F2644F，禁其他主色。

2. **下载**：`curl -sL -o scene.png <图URL>` 落到发布包 `03_封面/`。AI 候选版可落 `03_封面/点击率版候选/` 供 boss 对比挑选。

3. **HTML 覆字**（模板见同目录 `cover_template.html`）：
   - `body{width:900px;height:383px}`
   - 背景 `scene.png cover` + 从右到左加深的黑渐变遮罩（保证右侧文字可读；白底封面则反向用浅色遮罩或直接压字）
   - 文字压**右侧暗部**（路线 A）或**下方负空间**（路线 B）：主词（≤6字/行，白字或黑字，一个词用橙红 #F2644F 强调）+ 一行灰副标
   - **封面不复述标题**：只留 ≤1 主词，标题交给公众号原生标题栏
   - **不加合集 tag**（铁律 3）

4. **渲染**：
   ```bash
   python3 tools/fig_fit.py <cover.html> --width 900 --bg "#1a1a1a" --out <封面名>.png
   ```

5. **验收（不可跳过，OCR 回查）**：Read 亲眼看图——
   - **文字无错字**（铁律 1/2：AI 生图无文字，字是 HTML 压的，不会错；但仍要 Read 确认渲染没崩）
   - 文字无孤字换行（字数×字号<470px）
   - 路线 A：人物不露正脸；路线 B：简笔画风格统一、无 AI 乱码
   - **无合集 tag**（铁律 3：grep `.tag` 类字样 = 0）
   - 黑白底色与上一篇实发封面交替（查后台近期发表，不查包内旧备注）

## 黑白律动
一篇黑底一篇白底交替。黑底=场景图偏暗+白字；白底方向另出浅色场景图/简笔画白底。发完在台账记下本次用了哪个色。

## 落盘与同步
- PNG 落发布包 `03_封面/`；
- **封面=引子图同款**：首屏引子图复用同一张 PNG（DESIGN §二补 坑位67）：`cp 03_封面/封面.png 04_配图/00-封面引子图.png`；
- 改标题后必须重渲封面并 Read 复验；改封面后必须同步引子图。
