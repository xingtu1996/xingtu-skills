# exam-prep-pmp · 考证备考系统搭建（PMP式）

为在职备考者搭建可运行、可验收的备考系统。已验证于北邮MEM 2027（`github/xingtu-learn/20-cert/mem-2027`）。

## 输出物六件套（固定骨架）

```
<cert-dir>/
├── 00_章程/项目章程.md        # 启动：SMART目标/里程碑M0-Mn/预算授权/假设与排除项
├── 01_计划文档/PMP式备考执行规划.md  # WBS三层+活动清单+甘特+七知识领域
├── 02_真题与模考/真题与备考实践指南.md # 真题资产盘点+四级考试体系+考证状态DoD
├── 03_资源清单/               # 免费课/教材/采购渠道（闲鱼只买二手书，盗版课红线）
├── 05_模考数据/               # 分数追踪表+外部打卡数据源schema
└── 06_监控报告/               # KPI(SPI-lite)+周报模板+系统验收报告
```

## 关键设计决策（踩坑后沉淀）

1. **去重原则**：每日逐日任务 SSoT 单独一个文件（逐日执行总览），PMP规划只做管理层（范围/进度/成本/整合/沟通/采购/干系人/风险），引用不复制——否则两份计划必然漂移。
2. **主线资源免费化**：管理类联考=老吕(B站)+MBA大师+海绵MBA；英语二基础弱=田静语法+颉斌斌阅读+石雷鹏作文。付费班默认不采购，应急储备制（连续2次模考不涨才动用）。
3. **四级考试体系**：日练(墨墨+章节题)→周测(章节测30题)→月考(海绵月度模考看全国排名)→全真(W7起×6含涂卡)。排名比分数重要——在职自学最大盲区是不知道自己在什么位置。
4. **监控三KPI**：SPI-lite=完成活动/计划活动≥0.8；周时长（工作周≥10h）；单科3天正确率<40%→换资料（前置试错优于死扛）。
5. **每日打卡自动化**：automation_update 建 recurring（学习时段前15min），prompt 自包含：读逐日总览取今日任务→查昨日打卡→推送→写 checkin/→周日触发周验收。validUntil=考试日。
6. **端到端验收（"确保功能能实现"的应答方式）**：脚本实测五件事——关键文件存在/索引链接无死链/今日任务可grep提取/打卡文件可写/自动化已激活，输出验收报告+今日任务实跑演示卡片。不做验收=纸面规划。

## 流程

1. 读已有目录家底（README/plan/逐日），不推倒重来，只补管理层短板
2. 并行 WebSearch：名师资源(带B站播放量佐证)+院校实数据(复试线/综合成绩公式/学费/提面有无)+采购渠道风险
3. 写六件套 → 建打卡自动化（先 list 防重复）→ 跑验收脚本 → 更新 README 索引 → CHANGELOG
4. 假设必标注（如"北邮MBA"按用户已定的MEM处理；院校/渠道名听错的先推断再确认）
5. 收尾必给 boss 留 1 个待拍板项 + 1 个反思问题（苏格拉底式）

## 复用提示

- 软考高项-2027 可直接套骨架，替换：科目结构、真题年份段、分数线、考试日期。
- 院校信息以官网/研招网为准；本地产出禁放真题PDF原文与付费讲义（版权红线）。
