# 发布包规划（publish-pack-planning）

> **定位**：规划层。把「一个内容单元」变成「一整套可执行发布包」的物料地图。**只规划不执行**：各步实现 SSoT 在既有技能与 tools/，本技能只定顺序、清单、闸门、凭证。
> **分工铁律**：本技能 ≠ mp-publish-sop（那是执行层：成稿→草稿箱十步）；本技能管「发布包该有什么、按什么顺序规划、缺什么」，规划完交 mp-publish-sop 执行。分发细节交 xingtu-multiplatform-distribution，话术交 mp-group-push-copy，同步交 xingtu-article-sync。

## 适用范围守卫（首节，不可移）

读当前工作区根 `AGENTS.md`，正文含「行途」才继续；否则输出「publish-pack-planning 仅适用于行途工作区」并停止，不读任何业务文件。

## 触发时机（description 之外的关键场景）

- 用户要给一个想法/闪记/素材规划发布包（"这个能发吗/怎么发/发布包怎么搭"）
- 用户要求论证溯源（"论证一下/论据呢/这个说法对吗/素材库有支撑吗"）
- 用户要求物料清单（"这个发布包要准备什么"）
- 用户要求多平台内容（"分发裂变包/各平台发什么"）

## 规划五步（按序，每步有闸门）

### Step 0 论证溯源（成稿前必做，boss 2026-09-29 定）

**原则**：内容必须经过证实或证伪，遵循「论点 → 论证 → 论据」三段论；可解释、可溯源、能判断素材库。

1. **拆论点**：把内容拆成 1-3 个核心论点（每篇内容必须能说出"我在押什么注"）；
2. **补论证**：每个论点给出逻辑链（为什么这么说），不允许只抛结论不解释；
3. **配论据**：每个论证必须有证据，标注来源与验证程度：
   - ✅ 已查证（外部 URL / 官方来源）
   - 🟡 一方称（厂商自述 / 未核实引语）
   - 🔒 内部脱敏（cae 等一手实践，对外匿名化）
   - 📊 估算口径（如 60 人成本账，须注明"估算"）
4. **溯源素材库**：引用任何素材卡/选题卡/既有结论，必须回查 `素材库/素材库索引.md`（或对应 spec）确认存在与出处，**禁止凭印象引用**（B-009：素材没有的写【待补】不编造）；
5. **证伪检查**：主动找反证——这个论点有没有反例/边界？查不到反证也要说明"已知反例与边界"；
6. **可解释性**：结论必须能反推——"为什么得出这个结论"的证据链可完整展示（写进发布包 `_规划参考/论证溯源.md`）。

**闸门**：每篇发布包必须有 `_规划参考/论证溯源.md`（论点×论证×论据三级表 + 素材出处 + 反证与边界），缺则停止往下规划。

### Step 1 基础素材规划（(a) 标题/封面/截图配图）

| 物料 | 规划动作 | 实现指针 |
|---|---|---|
| 标题 | 出 3 候选（普世化公式：中文钩子前置 + 英文专名≤1）；撞题核查 | `mp-title-collision-rename`（双查阈值 🔴≥3） |
| 摘要 | ≤60 字，可转述 | `00_标题摘要/标题摘要.md` |
| 封面 | 黑白交替判定 + 三检（底色/交替/强调色 #F2644F/tag 禁篇幅） | `tools/cover_next.py` + `mp-publish-sop` Step 6c/7 |
| 配图/截图 | 图数/千字≥1（A 档 8-12 张）；概念图零水印；实操截图脱敏 | `pub-infographic-supplement` + `concept-anchor-figure` + `byted-mediakit-image` |
| 关键词 | BOSS 直聘真实搜索词 3 个（SEO/GEO） | `mp-publish-sop` Step 6b |

**闸门**：`00_标题摘要/` + `03_封面/` + `04_配图/` 三目录有规划产物（可先有占位/HTML 源，PNG 后出）。

### Step 2 发布操作素材规划（(b) 归档内容 + 发布记录）

| 物料 | 规划动作 | 实现指针 |
|---|---|---|
| 归档内容 | 旧版/中间版本一律进 `_archive/`（内部分层 01-06）；主目录只留发布必用 | PUB-031 |
| 发布记录 | 开箱操作单（认稿时间/媒体 ID/应删旧稿清单）；发布凭证（截图回填） | `mp-publish-sop` Step 9/10 |
| 发布前检查 | dry-run 预检 + 回看闸门（同题命中=0） | `mp-prepublish-draft-verify` + `tools/wx_draft_list.py` |

**闸门**：`06_发布参考/开箱操作单_<日期>.md` 存在（含认稿记录字段）。

### Step 3 分发与平台内容规划（(c) 裂变包 + 各平台发布内容）

| 物料 | 规划动作 | 实现指针 |
|---|---|---|
| 裂变包 | 公众号首发后 +24/48h 分发；一稿 N 平台差异化变体（禁通稿） | `xingtu-multiplatform-distribution`（规格卡/时序闸门/六平台结构级变体） |
| 各平台发布内容 | 平台级变体（掘金/知乎/CSDN 等）逐平台操作单；图卡 HTML→PNG | 同上 + `fig_fit.py` |
| 群推话术 | 四版话术（PEC/技术/行业/朋友圈）+ 置顶评论 | `mp-group-push-copy`（钩子=可转述反常识点） |
| 闭环凭证 | 发布后截图回填，闭环率 +1 | `mp-distribution-evidence-loop` |

**闸门**：`多平台分发_<包名>_<日期>/` 目录有操作单 + 变体；分发凭证命名 `分发凭证_<平台>_<日期>`。

### Step 4 包结构验收（六目录 + 规划件齐套）

```
发布包_<代号>/               # 如 AG-09_xxx / FDE-14_xxx
├── 00_标题摘要/             # 标题 3 候选 + 摘要 + 钩子 + 合集归属
├── 01_正文/                 # 正文_vN.md（最高版本 = SSoT，frontmatter 含中文 状态:）
├── 02_排版HTML/             # 公众号_发布版.html（mp-publish-sop Step 6 产出）
├── 03_封面/                 # 封面 PNG + HTML 源
├── 04_配图/                 # 引子图 + 正文配图（00-封面引子图.png 同封面）
├── 06_发布参考/             # 开箱操作单 + 群推话术
├── _archive/                # 旧版归档（内部分层 01-06）
└── _规划参考/               # 论证溯源.md + 战略/选题文档（本技能 Step 0 产物）
```

**验收闸门（三问）**：
1. 论证溯源.md 存在且每论点有论据标注？——缺 = 不打磨
2. 基础素材（标题/封面/配图）有规划产物？——缺 = 不排版
3. 分发与话术有规划？——缺 = 不发布（首篇可只发公众号，但必须有分发规划记录）

**DoD 通用口径**：只认磁盘凭证（文件存在 / mtime / grep 计数 / 门禁退出码），模型自述"已规划"不算数。

## 与既有技能的分工（防重复造轮子，本技能只引用不复制）
