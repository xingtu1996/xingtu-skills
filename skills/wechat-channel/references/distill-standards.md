# 微信通道 · 蒸馏标准（distill-standards）

> 与行途 `xingtu-ingest` / `session-sediment` 的价值体系一致。蒸馏结果按此标准执行，保证所有 Agent 产出同格式、可入库。

## 一、蒸馏四步

1. **分支切分**：`wechat_summary.py` 已按时间/话题把会话切成多个分支并生成 AI 摘要（`--gap` 控制切分间隔，默认 60 分钟）。
2. **主题归类**：把每个分支/要点归入主题，常用主题：AI工程化 / WorkBuddy / 知识复利 / AI工具 / AI商业化 / 技术工具 / 自媒体运营 / 其他。
3. **金句/方法论提炼**：提取可复用的金句、方法论、框架、对比维度。
4. **价值分级 + 落盘**：按下表判定价值，落到素材卡/选题池/黄金会话萃取。

## 二、价值分级表

| 级别 | 标记 | 判定标准 | 落点 |
|------|------|----------|------|
| 黄金级 | 🥇 GOLDEN | 独家一手实践/观点，低同质化，可独立成稿 | 素材卡（完整方法论） |
| 关键级 | 🔴 KEY | 强证据力的硬事实/数据/可复现步骤 | 素材卡（evidence 锚点） |
| 重点级 | 🟡 FOCUS | 重要方法论/框架/对比维度 | 素材卡（方法论类） |
| 高知级 | 🟢 INSIGHT | 认知升级型金句/知识点 | 金句库 + 可做短内容 |

## 三、素材卡模板

```markdown
# 素材卡 · {主题}（{YYYY-MM-DD}）

> 级别：{🥇/🔴/🟡/🟢} · 来源：微信「{会话名}」· 入库时间：{date}

## 一句话核心
{一句话}

## 要点
- {要点1}
- {要点2}

## 可复用角度
- 成稿方向 / 素材用途

## 关联
- [[相关素材]] · 后续动作
```

## 四、落点规则

| 内容类型 | 落点路径 | 命名 |
|----------|---------|------|
| 通用素材/观点/方法论 | `~/xingtu/素材库/素材卡_{主题}_{日期}.md` | 主题 2-5 字核心词 |
| 高价值会话萃取 | `~/xingtu/素材库/黄金会话萃取_{日期}.md` | 当日合并或新建 |
| 选题 | `~/xingtu/xingtu-vault/02_内容仓库 (Content Hub)/01_灵感与选题池/2026-选题池.md` | 追加行 |
| 元宝内容 | `~/xingtu/xingtu-vault/02_内容仓库 (Content Hub)/06_元宝对话挖掘/` | 元宝文章_{标题}_{token}.md |

**登记**：入卡必登记到 `~/xingtu/素材库/素材库索引.md`。

## 五、铁律

1. 先分析后入库：先判价值定级别，不无脑追加。
2. 追加式不覆盖：同日已有文件则续写。
3. 增量不重复：元宝抓取走水位线，绝不重复抓全量。
4. 脱敏：涉及当前雇主/薪资/入职年限/隐私按用户偏好模糊化。
5. 诚实标注：无法判级或来源不明时标注"待核实"。
6. 本地零 token 优先：解密/提取/读取全部本地完成；只有蒸馏总结才调用 AI。
