# 群推话术四版 + 置顶评论生成管线（mp-group-push-copy）

> **适用范围守卫**：专为「行途」工作区的发布包结构（`01_正文/ … 06_发布参考/`）与台账（`data/manual_metrics.json`、`outputs/发布包_*/`）设计。当前工作区不存在这些目录/文件时（如公司侧仓），声明不适用并停止，不套用本流程给其他项目写传播文案。
> 本 skill 只负责**生成文案**。三方分工不越界：

| 要做的事 | 走哪 |
|---|---|
| 生成群推话术 + 置顶评论 + 节奏表（本技能） | `06_发布参考/群推话术与置顶评论_<发布日期>.md` |
| 建稿、设封面原创、群发、发布后照贴置顶 | `wechat-mp-publish`（其发布步骤是**取用**本技能产物，不现写） |
| 发前事实回源、图文同步、dry-run 嵌图、回收缺陷稿 | `mp-prepublish-draft-verify` |
| 发布后铺掘金/知乎/CSDN/小红书/抖音/X 变体 + 图卡 | `xingtu-multiplatform-distribution` |

**为什么这是标配件而非可选项**：`data/manual_metrics.json` 的 `judgements` 有已验证研判——分享数是关注杠杆、群推话术是触发器（PEC 26 分享 / FDE-02 17 两篇为 boss 确认关注来源；**取值以该文件为准，勿抄录具体数字进文案或本文档**）。搜一搜与群推是两条独立入口，阅读数不是唯一决策依据。被验证起量的篇目共同点：**给了群里的人一个可以转述的反常识点**——本管线一切设计服务于把钩子位放上一个可转述点。

## 三底座（开工前先读，缺一动笔即违规）

1. **家族存档**（三版结构 + 五条纪律）：`ls outputs/发布包_*/_archive/已发布/*/06_发布参考/ | grep -i "群推\|置顶"` 读最近 1~2 份。结构基准：`0911_B15斩杀线_Flash追上Pro/06_发布参考/群推广文案_2026-09-11.md`
2. **boss 实测 PEC 骨架**（最高优先）：承接上篇谢反馈 → 说清来源（真实做了什么）→ 结构钩子（反常识点）→ 一家之言欢迎指正。成品范例：`outputs/发布包_2026-09/AGENT-03_Agent三国杀_WorkBuddy豆包千问/06_发布参考/群推话术与置顶评论_2026-09-16.md`
3. **置顶评论格式（历史样例，仅看语气）**：`outputs/发布包_2026-09/MODEL-02_速评02_DeepSeekV4Pro/06_发布参考/置顶评论.md`。⚠️ 该样例是**已废弃的「1 主选 N 备选 + 留言区堆标签」旧格式**，只作口吻参照；现行结构以 Step 5 **三层顺序**为准，且留言区不放手动 `#`。

若 boss 提供新的实测截图（某群发出去带来关注的真实话术），**以截图骨架为最高优先级基准**，家族存档次之，自己手感最低。

## 七步流程（按序执行）

### Step 1 · 定位发布包，取真标题真摘要

从 `01_正文/正文_v<最大>.md` 与 `06_发布参考/开箱操作单_<发布日期>.md` 取：真标题、真摘要、定时发布时间、正文小节号（话术里"答案在第 8 节"这类指代必须核到实际节号，不凭印象）。

### Step 2 · 对齐家族写法（必做，不许凭手感现编）

按三底座逐一读，不凭记忆复述结构。沿用家族不变量：**像分享不像广告、先钩子后链接、不带"求转发/求赞/关注"字样、单群只发一次、先 1-2 个最熟的群试水温隔天再铺**。

### Step 3 · 提炼钩子——本技能唯一的质量变量

从正文抽 **1 个可转述的反常识点**：判据是"群里一个人看完，能不能原样复述给第三个人听，且第三人会追问链接"。

**活人动机链模板（v1 被打回后 boss 沉淀的最高优先钩子来源）**——钩子必须挂在"我为什么去做这件事"的活人动机上，而不是"这三个东西谁强"的产品对比上。公式：

> `老板/外部提问（要不要上 X）→ 我真把 N 家跑了一遍 + 翻了某公开数据 → 一半是给老板汇报的底稿、一半是自己拓认知提判断 → 替群里同类朋友省一周调研`

用这条链写钩子时，还要**承接上篇分享、保持系列连贯**（v1 因"产品对比视角与前几次 FDE 分享不连贯"被打回）。

- 合格形态：一个带落差的陈述句（数字反差 / 排名反差 / 我们为什么没选 X / 两个常被混为一谈的东西不是一回事），且能回溯到上面的活人动机链。
- 不合格：主题介绍（"这篇讲了办公 Agent 怎么选"）、形容词堆砌（"干货满满"）、正文里没有的论点，**以及纯"产品对比 / A-B-C 横评"视角**（"我把三家放一起比了比"没有活人动机 = 像机构测评，不是钩子）。

第 1 层置顶反差钩若一时选不出理想形态，可套两个候选钩型找感觉：**征集钩**（引回复 + 为下一篇攒素材）、**导流钩**（把读者送到某一节）。

**选不出可转述点 → 停下回炉正文**，报告 boss"这篇没有可转述的反常识点"，不靠话术硬撑。话术救不了没有钩子的稿子。

### Step 4 · 写四版话术

按 `templates/promo-copy-template.md` 填空：

- **版 A · PEC / 参会者群**——照 boss 实测四段骨架（①承接谢反馈·接上篇保持系列连贯 ②说清来源 ③结构钩子含榜单/数字反差 ④一家之言欢迎指正）。③ 位填的是 Step 3 的**活人动机链**（我为什么去做 → 换了一个什么切法），**不是"三家谁强"的产品对比**（v1 就栽在这里）。**这一版是全管线里被验证过的版本，优先级最高。**
- **版 B · 技术 / 工作群**：一句话"刚写完的 + 文里有什么硬货（账本/清单/步骤）+ 留给读者的问题"，克制、零营销腔。
- **版 C · AI 交流群 / 行业群**：数据钩子开场（真实数字+来源）+ "我换了一个切法" + 以问句收尾引拍砖。
- **版 D · 朋友圈 / 熟人群**：最短、两行内，一个反差 + 一句"几分钟看完"。

链接一律写 `<LINK>`（发布前真实链接不存在，写假链接 = 死链事故）。

### Step 5 · 写置顶评论（三层顺序，非"一条主选"）

boss 09-16 拍板：置顶不是一条文案，而是**发布后按顺序落地的三层留言**。产出时按这三层写死，让 boss 照贴即可：

1. **第 1 层｜置顶反差钩**（发布后 30 分钟内，点「作者精选」置顶）：一个**给读者能答的选择题**式反差钩（榜单/数字落差 + 收在问句），既引回复又为下一篇攒素材。**这条是唯一被置顶的留言。**
2. **第 2 层｜@AI 总结（普通留言，不置顶）**：隔 10–20 分钟，在留言框 `@` 公众号绑定的 AI 助手（如元宝）触发一句话总结。它带「内容由 AI 生成」灰标——**放最显眼的置顶位 = 把最没活人味的内容顶到门面**，故只作普通留言，排在置顶下面，不冲突也不互顶。
3. **第 3 层｜作者追评收口**：AI 回复后，作者在该条下追评一句**自己的判断**（AI 总结 + 作者补刀 = 信息密度加活人味）。

**若 boss 只想留一条**：保第 1 层反差钩，砍第 2/3 层——作者连占两条以上留言会显自嗨。

**空气对话感检查**（写完第 1 层必过）：把置顶钩子读完，模拟一个一直沉默的读者——**他能不能顺手回一句话？** 能答 = 有效；只能"嗯/确实"接不下 = 空气对话（自言自语），回炉重写直到给出一个可表态的选择题。

**留言区 `#` 串纯文本判定**：留言框手动打的 `#xxx` 是**纯文本**，永远不变绿、不可点、不进话题页，堆在评论末尾只剩"堆关键词"的营销感。**留言区一律不放 `#` 串。** 想要话题流量，在**正文**里用编辑器「话题」组件插 1–2 个核心话题（话题页流量吃正文话题，留言区话题标签几乎无流量）。

> **PUB-050 边界说明**：PUB-050 的"标签 ≤5、长尾词优先"口径针对的是**正文话题组件**，**不授权在留言区手动堆 `#`**。细则读 `rules/RULES.d/01_PUB*.md`，不在本文档复述。

两条操作口径沿用：

1. 产出**可直接复制的最终文案**（三层各一段），不写说明性散文——发布后 30 分钟内是手忙脚乱的窗口，任何"这里可以再改改"都会导致现场现写。
2. 第 1 层优先选**征集/反差钩**：既引回复，又给下一篇攒真实素材（评论区是免费的选题调研位）。

### Step 6 · 落盘 + 节奏表

写 `$P/06_发布参考/群推话术与置顶评论_<YYYY-MM-DD>.md`（**文件名日期 = 发布日期，不是今天**；PUB-031 六目录规范），五节：依据三行 → 一、置顶评论 → 二、群推话术四版 → 三、节奏与时段 → 四、为什么这篇强调这个钩子。

节奏表（沿用家族实测，按当日定时时间平移）：

- **群分层与沟通式分享（boss 09-18 拍板，覆盖旧"每天定时试水温"默认）**：群分两类——**自家地盘/熟人群**（PEC 群、自己管理的群、朋友圈）：可按节奏定时试水温；**他人管理群/泛技术群**（群主在意的群、290 人大群等）：**只沟通时分享、不定时营销**——相关话题被聊到顺势发（"刚聊到这个，我写过一篇…"），没话题不硬推；每天定时轰炸 = 观感差、易被移除群聊。判断口诀：**"群主会不会觉得我在拉人？"** 会 → 只沟通时分享，甚至只潜水收情报不发。
- 发出 → **30 分钟内按 Step 5 三层顺序落地**：① 置顶反差钩（点「作者精选」）② 隔 10–20 分钟 @AI 总结作普通留言不置顶 ③ AI 回复后作者追评收口。正文话题是否生效看评论区顶部「都在搜」是否捞到**正文话题组件**的词（留言区不带 `#`，不作此检查）；有人回复后补一条收口句把讨论引回文章。
- 上午 09:30–10:30 发版 A（PEC 群）+ 版 B（一个最熟技术群）试水温 → 隔天铺版 C 行业群 → 版 D 朋友圈 21:00 后。（仅限自家地盘/熟人群）
- 单群只发一次；群里有人问细节回"文里第 N 节有清单"，不另发长文解释。
- **必须写入留痕要求**：每发一个群截图留痕，回填 CHANGELOG + 台账。分发凭证是矩阵当前最大缺口——没有截图，下一轮无法判断哪版话术有效。

### Step 7 · 收口

```bash
python3 tools/changelog_append.py --type "🆕" \
  --path "outputs/发布包_YYYY-MM/<包名>/06_发布参考/群推话术与置顶评论_<发布日期>.md" \
  --desc "群推话术四版+置顶评论+节奏表（钩子=<可转述反常识点>）" --tool qwenwork
```

在 `开箱操作单_<发布日期>.md` 动作清单加一行指向该文件（boss 早上开箱即见"贴哪份、发哪版"）。话术若引用新的对外数据断言，`python3 tools/privacy_scan.py --fail-fast` 一并跑（文案也要过隐私门禁）。

## Pitfalls（实测坑）

- **拿产品对比冒充钩子**：话术写成"我把三家放一起比了比谁强"= 机构测评腔、跟前几次分享不连贯、缺活人味（v1 被打回原话）。钩子必须挂 Step 3 活人动机链（我为什么去做 → 换了什么切法）。
- **置顶放 AI 总结 / 自言自语**：把带「内容由 AI 生成」灰标的 AI 总结、或读者接不下的自high 句放置顶位 = 门面最没活人味。置顶只放**能给读者答的选择题反差钩**；AI 总结作普通留言不置顶，作者再追评收口。写完第 1 层必过「空气对话感检查」。
- **留言区堆手动 `#` 串**：留言框手输的 `#xxx` 是纯文本，不变绿不可点不进话题页，只增营销感。留言区不放 `#`；要话题走**正文话题组件**。
- **把"主题"当"钩子"**：介绍内容的话术没人点开。钩子必须是带落差的判断句，能被人原样转述。
- **PEC 群版丢四段骨架**：直接套通用群发模板 = 掉进"像广告"。承接上篇 + 说清来源是被验证带来关注的部分。
- **抄上一版话术只换标题**：反常识点必须本篇专属；标签同理——家族存档的标签属于上一篇的长尾词，照抄 = 搜一搜索引串味。
- **`<LINK>` 忘替换**：发出前逐版检查，四版各一处，共 4 个占位。
- **现场现写置顶评论**：违反 PUB-050"标配交付物"要求，发布窗口内现写必然凑数。
- **群发时序早于发布**：定时稿在群里的卡片会露出全文，声明原创的排期稿**首发前不进任何公开展示位**（铁律 9 同源）。群推话术只在文章实际可见后发放。
- **私域加戏**：话术里出现"昨天连麦/昨晚那场讨论/内部朋友说"等无源私域场景 = 与正文同类事故（B-009）。来源只写能公开复现的动作。
- **不承诺效果**：不对 boss 说"发了会涨粉/会带来 N 个关注"。分享数是杠杆这条有数据，单篇效果无凭据。
