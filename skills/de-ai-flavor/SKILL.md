# 去 AI 味（De-AI-Flavor）· 行途技术适配版

> 核心理念：**一个具体细节 > 三个抽象形容词。** AI 味的本质是"用形容词替代证据"。
> 真实的人说人话：有数字、有场景、有动作、有代价。

## 零、三条元原则（先于检测清单，2026-09-20 补入）

> 补入动因：本 skill 此前通篇是「命中即改」，缺一条**反向约束**——过度改写同样会毁掉人味，甚至比 AI 味更糟（把作者的声音改没了）。三条元原则约束「改的边界」。
> 来源借鉴：豆包 `doubao-human-signal` v2.2.9（Apache 系授权目录外的纯提示词 skill；仅借鉴方法论，未引入其代码资产）。

**1. 保真第一 —— 只改「怎么说」，不改「说什么」**
不编造、不丢信息、不弱化事实、数字、引用、来源、限定条件和风险提示。
- 改写只允许动**表达层**（措辞/语序/语气），不允许动**事实层**（数据、归因、边界条件）。
- 反例：为了让句子利落，把「CI 一次通过率 >90%」改成「通过率很高」——这是把证据改成形容词，方向正好反了。

**2. 低误报 —— 允许判定「不需要大改」**
原文已经自然、有作者声音，或体裁本身需要正式工整（公文/技术规范/法律文本）时，**可以、也应该说出「这里不需要改」**。
- 去 AI 味的目的是「读起来像人」，不是「必须找出毛病」。找不到毛病时报「通过」，不硬凑修改量。
- 反例：为了体现工作量，把一段本来就干净的叙述逐句「优化」一遍，改完全篇变成另一种均匀腔调——**均匀本身就是 AI 味**。

**3. 风格保真 —— 学样本的节奏，不套通用人味**
优先保留用户自己的声音。有风格样本（作者过往文章/口述转录）时，学它的**节奏、词汇、分寸和判断方式**，而不是套一个通用的「朋友圈口语」模板。
- 行途技术语境的默认样本 = 作者已发文章与口述转录；不同作者/不同栏目的人味不一样，不能用一个模板通吃。
- 反例：给一个克制的技术作者硬塞「说真的」「老实讲」这类口语填充，人味没加上，反而多了一层假。

**三条原则与下文清单的关系**：下文清单负责「找出可疑处」，本节负责「判断该不该动」。**清单命中 ≠ 必须改。**

## 一、AI 味信号检测清单（命中即改）

| 信号 | 特征 | 例子 |
|------|------|------|
| **空泛形容词** | 无证据的自我标榜 | 利他 / 实干 / 可复用 / 赋能 / 深耕 / 沉淀 / 前沿 / 专业 |
| **口号式对称** | 排比句 / 三连顿号 / 对仗 | "不堆概念，只讲踩过坑、跑通过、能复用的东西" |
| **万能结论** | 任何话题都能套的收尾 | "未来已来" / "一起成长" / "让我们拥抱 AI" |
| **空承诺** | 无法验证的虚话 | "领先市面常见方案" / "深受好评" |
| **伪逻辑** | "X 是 Y 的前提"式断言 | "利他 = 信任成本 = 变现前提" |
| **过度抽象** | 无数字无场景无工具名 | "把前沿实践快速转成可发布内容" |
| **粗俗 / 过糙用词** | 见过血但没打磨，读着像群聊而非成稿 | 扔 / 甩 / 干了 / 搞了 / 一堆 / 土 / 干不了 / 糙 |
| **营销腔 / 夸张修辞** | 用拔高语调替代事实描述，像软文不像在场记录 | 顶到了最高处 / 拉满 / 引爆 / 王炸 / 天花板 / 降维打击 / 最狠的一击 / 直接封神 / **问爆 / 刷屏 / 炸了 / 杀疯** |
| **口癖过量** | 单个虚词反复出现，稀释信息密度 | 其实 ×N / 特别 ×N / 本质上 ×N / 就是 ×N |

### 定量检测手法（比目测准）

用脚本对全文做**词频统计**，超过经验阈值就降噪：

```python
for w in ["其实","说白了","本质上","特别","非常","就是","而且","真的","越来越"]:
    print(w, text.count(w))
```

经验阈值（1 万字稿）：`其实 / 本质上 / 说白了` 各 ≤4；`特别 / 非常` 各 ≤5；`越来越` 建议 0（除非是引语）。
**注意**：引用他人原话里的口癖不算 AI 味——那是人味，保留并标注。

### 三类"假人味"要跟"真粗俗"分开

- **真粗俗**（改）：作者自己的行文用了扔/甩/搞/一堆
- **引语里的糙话**（保留）：现场原话"是不是天天在骂你？"——删了就假了
- **作者自评的糙**（保留但转述）：讲者自称"我的做法比较粗暴"，写成"他自己说，他的做法'比较粗暴'"即可，别由作者替他下判断

## 二、改写策略（检测到 → 这样改）

1. **数字说话**：能量化的给量化。`"提效明显"` → `"生产问题排查从 4-5h 压到 30min（8-10x）"`
2. **动词 + 对象**：具体动作 + 具体对象，不是形容词。`"沉淀 AI 实践"` → `"用 ai_history_indexer 扫了 1056 个会话，挑出 12 个选题"`
3. **删空话**：删掉后意思不变的形容词直接删。`"坚持把前沿实践快速转成可发布内容"` → `"每周把两个跑通的实践写成稿"`
4. **留代价与前提**：真实感来自边界，不是全优。`"零返工"` → `"CI 一次通过率 >90%，返工发生在 Spec 阶段"`
5. **口语化**：像跟同行线下聊天，不写宣传稿。"这个坑我踩过"优于"这是一段宝贵的成长历程"

## 三、应用步骤

1. 全文扫一遍，标出命中信号的句子（用上面的清单）
2. 每条问："删掉/换成数字/换成场景，意思还在吗？" 在 → 改
3. 改完重读一遍：读起来像不像一个干过活的人在说话？不像 → 继续改
4. 保留用户真实表达的口语/语气（哪怕不够"高级"），那是人味

## 四、质检

- [ ] 无空泛形容词（利他/实干/深耕/赋能 等在无证据时禁止）
- [ ] 有 ≥2 个具体数字或场景
- [ ] 无口号式排比 / 万能收尾
- [ ] 无作者行文里的粗俗用词（引语内的糙话保留）
- [ ] 无营销腔夸张修辞（顶到最高处/拉满/引爆/王炸/天花板类拔高语调）
- [ ] 口癖词频已用脚本统计过，超标项已降噪
- [ ] 加粗数量 ≤10（长文也一样）——加粗过密本身就是 AI 味；**行途技术口径见 PUB-027：≤8**
- [ ] **数一数加粗都加在哪：如果超过 5 处是「列表条目的引导词」（1. **存量依赖**。2. **结算结构**。／① **怎么选？**），那不是强调，是你替读者划重点——把引导词加粗全去掉，只留 1~3 处真正锋利的句子**（2026-09-14 MODEL-02 实测：19 处加粗里 14 处是列表引导词）
- [ ] **反向自查（§零 三原则）**：① 有没有把**事实/数字/限定条件**改成形容词（保真）？② 找不到毛病时有没有硬凑修改量（低误报）？③ 改完的腔调还是**作者自己的**，还是变成了一个通用模板（风格保真）？
- [ ] 读起来像人在说人话

## 五、真实案例（2026-09-13 · TREND-03 PEC 复盘长文）

boss 反馈原文：「扔 有些粗俗了，粗俗话语检查，另外去 AI 味，活人感生产优化。」

一轮过下来命中 15 处，分三类：

| 类 | 命中 | 改法 |
|---|---|---|
| 粗俗/过糙 | 标题「先**扔**了两句话」、最"**土**"的一个、"**搞**了四五十个"、模型**干不了** | 换成中性但仍有画面感的词：给了 / 最不起眼也最实在 / 做了 / 做不了 |
| 空泛词 | 「**本质上**是管理流程变更」「**沉淀**成**可复用**的资产」 | 回原话「这其实是个管理流程变更的问题」；"攒下来、下次能直接拿出来用" |
| 口癖降噪 | 特别 ×5 处、本质上 ×1 | 换词或直接删：很认同 / 专门强调 / 我觉得更聪明 / 我到现在还记得 |

**同时补了两处活人感**（不加长度，只换写法）：
「主持人开场就把调子定得很高」→「椅子还没坐热，主持人第一个问题就问得很大」；
「这场我本来打算随便听听」→「抱着**听热闹**的心态去的」。

**一条重要发现**：加粗过密和口癖过量是同一个病——**作者在替读者划重点**。人写东西不会每段都划重点。

## 六、二轮返工案例（2026-09-13 同日 · 营销腔 ≠ 活人感）

boss 对上节「活人感」改写的直接返工：「主持人就把问题顶到了最高处。**这太营销了吧。**」

| 项 | 内容 |
|---|---|
| 原句（一轮改写产物） | 「椅子还没坐热，主持人就把问题顶到了最高处」 |
| boss 判定 | 太营销 |
| 终稿 | 「椅子还没坐热，主持人第一个问题就问得很大」 |
| **教训** | **夸张修辞不是活人感，是营销腔。** 活人感来自具体与克制（椅子还没坐热 ✓），不来自拔高语调（顶到了最高处 ✗）。一轮改写时把「调子定得很高」翻成更响的说法，等于把形容词换成了更夸张的形容词——病没换，只是加重了 |
| **判定句** | 「这句话放进楼盘广告或发布会通稿里违和吗？」不违和 = 营销腔，改 |

## 七、三轮案例（2026-09-14 · 营销腔会藏在「小标题」里）

boss 对 MODEL-02 小标题「群里被**问爆**的三个问题」的判定：「问爆了，太营销了。」

| 项 | 内容 |
|---|---|
| 原句 | 群里被**问爆**的三个问题 |
| 改法 | 群里**问得最多**的三个问题 |
| 为什么 | 「问爆」是结果夸张（无法验证的强度副词），「问得最多」是**可验证的事实描述**——同一个意思，一个在喊，一个在说 |
| **教训** | **营销腔不只藏在正文，小标题/章节名/目录尤其高危**——标题位天然倾向「抓眼球」，最容易滑向拔高。**扫标题位要单独扫一遍**（正文顺，小标题仍可能全是「爆/刷屏/炸」） |
| **通用替换法** | 强度副词 → 可验证描述：问爆→问得最多；刷屏→很多人转；炸了→反应很大；杀疯了→表现远超预期 |
| **同类历史** | PEC 复盘「调子很高」→「顶到了最高处」（更糟）→「第一个问题就问得很大」（终稿）。**换成更响的说法 ≠ 改掉营销腔，是加重它** |
