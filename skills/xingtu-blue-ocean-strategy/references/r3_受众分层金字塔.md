# R3 · 受众分层金字塔

> 目标：回答「完整的人群金字塔长什么样？我主攻哪一层？他们的痛点和付费意愿如何？」——产出**分层金字塔 + 核心人群画像 + 付费产品适配矩阵**。

## 一、分层方法（建议 5 层）

从最资深到最入门画金字塔，每层必须填全以下字段：

| 字段 | 说明 |
|------|------|
| 人群定义 | 经验/角色/背景的准确描述 |
| 规模估算 | 全球 + 本土（标注口径） |
| 使用程度 | 对品类工具/产品的使用深度 |
| 核心痛点 | 按真实痛感描述，不是泛泛而谈 |
| 付费意愿与能力 | 收入水平 + 付费动机强度 |
| 内容/产品偏好 | 语言风格、内容形态 |
| 是否你的目标 | ★核心 / ⚠️次要 / ❌非目标 + 理由 |

## 二、分层判断的黄金法则

1. **不要往上走**：最资深层通常不是你的目标（已有强势竞争者，且你的「普惠」表达不适合）
2. **不要往下走**：最入门层付费意愿极低，做入门内容会稀释专业定位，且竞争最激烈
3. **牢牢占据腰部**：中间 2 层（有基础但非资深 + 新涌入的外行）通常是甜蜜区——规模够大、付费意愿够强、竞争够少、你的背景表达完全匹配
4. **用存量层的内容吸引增量层，用增量层的故事共鸣存量层**——两层共享同一核心理念，但语言和案例不同，可交叉引流

## 三、核心目标人群画像模板

给每个核心目标层写 **5 个典型人物画像**（角色/年龄/场景/困境）+ **共同特征** + **核心需求排序**：

```markdown
### Lx：{层名}（★核心目标）
**典型人物画像**：
- {姓名}，{年龄}，{角色}，{场景描述}
- ...
**共同特征**：{年龄区间/基础/使用情况/付费能力/搜索习惯/对专业内容的距离感}
**核心需求**（按强度排序）：
1. {需求1}
2. {需求2}
...
```

## 四、付费意愿分析

### 付费动机矩阵
| 付费动机 | 存量层 | 增量层 |
|---------|--------|--------|
| 省时间 | ★-★★★★★ | ★-★★★★★ |
| 少踩坑/防翻车 | ★-★★★★★ | ★-★★★★★ |
| 提升能力 | ★-★★★★★ | ★-★★★★★ |
| 职业/事业发展 | ★-★★★★★ | ★-★★★★★ |
| 焦虑缓解 | ★-★★★★★ | ★-★★★★★ |

### 付费产品形态适配矩阵
| 产品形态 | 价格区间 | 存量层适配 | 增量层适配 | 说明 |
|---------|---------|----------|----------|------|
| 低价单篇 | ¥1-10 | ★ | ★ | 试水用 |
| 小册/电子书 | ¥49-99 | ★★★★★ | ★★★★ | 最适合的入门产品 |
| 体系化课程 | ¥199-399 | ★★★★ | ★★★ | 存量层愿意付费 |
| 社群/陪跑 | ¥365-599/年 | ★★★★ | ★★★ | 增量层价值大需持续运营 |
| 1v1 咨询 | ¥199-699/次 | ★★★ | ★★ | 特定问题付费 |
| 企业服务 | 万元级 | ★★ | ★ | 成熟期考虑 |

### 付费转化关键杠杆（通用原则）
1. **「避坑/防翻车」比「提升」更有付费驱动力**——用户更怕损失而非渴望收益
2. **「可抄作业」比「讲道理」更有付费驱动力**——目标人群要的是模板和清单
3. **共鸣感是信任基石**——创始人的真实成长故事是最大的差异化资产
4. **「从玩具到生产力」式精准定位是转化钩子**——直接命中最大痛点
5. **免费建立信任，付费提供深度**——免费引流，付费沉淀

## 输出模板

```markdown
## 一、五层人群金字塔（ASCII 图 + 每层规模标注 ★目标）
## 二、逐层详细分析（每层一张字段表）
## 三、目标人群总规模汇总（各目标层全球/本土/占大池子比例）
## 四、核心目标人群详细画像（典型人物 + 共同特征 + 需求排序）
## 五、付费意愿分析（动机矩阵 + 产品适配矩阵 + 转化杠杆）
## 六、分层战略启示（往上/往下/腰部/交叉引流结论）
```

## 常见坑
1. 分层只看规模不看付费意愿（每层必须标付费意愿）
2. 画像写成虚构的完美用户（必须来自真实痛点/访谈/社区观察）
3. 所有目标层用同一套语言（存量层和增量层要不同表达）
