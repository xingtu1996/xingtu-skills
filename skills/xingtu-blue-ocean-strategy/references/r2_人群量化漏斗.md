# R2 · 可变现人群量化（漏斗法）

> 目标：回答「从全球/大池子人口到我能实际触达的付费人群，到底有多少人？每层转化率多少？」——产出**漏斗模型 + 三口径结论 + 变现节奏**。

## 一、8 层漏斗方法

从最外层到最内层逐层收窄，每层给出：规模 + 数据来源 + 估算逻辑 + 查证状态。

```
L1 大池子人口（如全球/全国人口）
L2 可触达基础用户（互联网用户/平台用户）
L3 品类相关人群（该领域从业者/兴趣者）
L4 使用过该品类工具/产品的人数
L5 目标细分人群（对应你的定位的窄人群）
L6 大范围付费用户（知识付费/消费意愿人群）
L7 平台生态内可触达人群（对应你的发布平台）
L8 你可实际触达的付费人群（按转化漏斗建模）
```

- **L1-L5 用公开统计**：人口/渗透率/从业者/工具用户量（去重估算）
- **L6-L7 用平台数据**：平台月活 × 品类关注比例（估算）
- **L8 用转化漏斗建模**：曝光→阅读→关注→付费→复购，用行业基准转化率推算当前/增长/成熟三阶段

## 二、L8 转化漏斗建模（核心）

| 阶段 | 假设条件 | 当前阶段 | 增长阶段 | 成熟阶段 |
|------|---------|---------|---------|---------|
| 月曝光量 | 粉丝 × 50-100 倍 | ... | ... | ... |
| 点击阅读率 | 3-5% | ... | ... | ... |
| 关注转化率 | 2-5%（阅读→关注） | ... | ... | ... |
| 付费转化率 | 0.5-2%（关注→付费） | ... | ... | ... |
| 客单价假设 | 产品形态决定 | ... | ... | ... |
| **月收入估算** | 前几行相乘 | ... | ... | ... |

**行业基准参考**：曝光→阅读 2-8%；阅读→关注 1-5%；关注→付费 0.3-3%；付费→复购 20-50%。实际结果受内容质量/更新频率/定位精准度影响极大，需每月复盘动态调整。

## 三、三口径法（避免「数字游戏」）

同一个目标人群必须给三种口径，防止被质疑夸大：

| 口径 | 定义 | 规模 | 可信度 |
|------|------|------|--------|
| A 最宽口径 | 潜在兴趣人群（知道该品类存在、可能点击） | ... | 🟡 估算 |
| B 中等口径 | 活跃使用者 + 有付费意愿 | ... | 🟡 估算 |
| C 最窄口径 | 你可实际触达 + 高转化可能 | ... | 🔴 推测 |

**结论句式**：「无论哪种口径，人群规模都足够支撑一个中型 X 的变现。关键不是人群够不够大，而是内容/产品够不够精准、更新够不够持续、信任够不够深厚。」

## 四、变现节奏（四阶段）

| 阶段 | 时间 | 规模目标 | 收入预期 | 核心任务 |
|------|------|---------|---------|---------|
| 冷启动期 | 0-6 月 | 小→中 | 低 | 质量打磨、定位验证、种子用户 |
| 增长期 | 6-12 月 | 中→较大 | 中低 | 持续输出、低价产品试点、社群启动 |
| 加速期 | 12-18 月 | 较大→大 | 中高 | 体系化产品、高阶服务、规模化 |
| 成熟期 | 18-24 月 | 大→更大 | 高 | 品牌溢价、高端服务、多平台矩阵 |

关键原则：前期**不以变现为目标**；小规模破 N 后可启动低价产品测试付费意愿；更大规模后上中价产品；再往后才考虑高价服务。

## 输出模板

```markdown
## 一、8 层漏斗总览（ASCII 图 + 每层规模）
## 二、逐层详细数据（每层：指标表 + 来源 + 查证状态）
## 三、关键转化率假设（行业基准 + 你的预期 + 依据）
## 四、三种口径结论（宽/中/窄 + 结论）
## 五、变现节奏建议（四阶段表）
```

## 常见坑
1. 只给最宽口径数字（必须三口径并给出可信度）
2. 转化率拍脑袋（必须标注行业基准来源）
3. 把「使用过」当「持续使用」算付费（要乘活跃比例）
4. 收入估算不标注「推测/乐观」边界（必须写「实际取决于运营能力」）
