# R5 · 方向锁定与行动路线图

> 目标：回答「我应该锁定哪个方向？为什么？接下来 90 天具体怎么做？」——产出**多方向对比矩阵 + 明确推荐 + 90 天路线图**。

## 一、多方向对比矩阵（决策核心）

把候选方向（通常 3-5 个）放成列，8 个评估维度放成行：

| 评估维度 | 方向 A | 方向 B | 方向 C | 方向 D |
|----------|--------|--------|--------|--------|
| **市场规模** | 大/中/小 + 一句话依据 | ... | ... | ... |
| **竞争烈度** | 🔴极高/🟠高/🟡中/🟢低 | ... | ... | ... |
| **你的匹配度** | 🟢高/🟡中/🔴低 + 依据 | ... | ... | ... |
| **变现潜力** | 高/中/低 + 验证证据 | ... | ... | ... |
| **内容/产品可持续性** | 是否随技术迭代而过时 | ... | ... | ... |
| **进入壁垒** | 高/中/低（是否谁都能做） | ... | ... | ... |
| **与已有资产协同** | 是否与书/产品/粉丝/经验互相放大 | ... | ... | ... |
| **利他价值** | 是否解决真实痛点、难被替代 | ... | ... | ... |
| **综合评分** | X.X/5 | ... | ... | ... |

> 打分要有依据（数据/竞品/自身资产），不是拍脑袋。推荐使用「主方向 + 支撑方向」组合，而非单选。

## 二、推荐结构写法

```
### 主方向 = {方向 X}（差异化锚点）+ {方向 Y}（深度支撑）
**以 X 为差异化锚点，以 Y 为深度支撑，形成「入门→进阶」的完整路径。**

### 推荐理由（N 条，每条必须含证据）
1. 缺口真实且巨大，先发优势明显（引 R1/R4 数据）
2. 你的独特性不可复制（个人路径/复合能力/背景稀缺）
3. 与已有资产协同，形成飞轮（书/产品/粉丝/经验互相引流）
4. 进入壁垒高，护城河深（复合能力别人难复制）
5. 内容/产品可持续，符合「历久弥新」定位（不随技术迭代过时）
6. 变现路径清晰，客单价逐步提升（免费→低价→中价→高价四层）
7. 利他第一性，真正解决用户痛点（带来忠诚与口碑）
```

### 不推荐方向及原因（每个明确写：红海/过时/冲突/变现难/非优势，并给出「可作引流但不能做主方向」的降级建议）

## 三、内容/投入占比建议

用表格给出各方向的占比分配 + 「关键转变」说明（说明从旧结构调整到新结构的理由）：

| 内容/投入类型 | 原目标 | 建议调整 | 说明 |
|-------------|--------|----------|------|
| {主方向} | ... | **NN%** | 差异化锚点，核心占比 |
| {支撑方向} | ... | **NN%** | 深度支撑 |
| {引流类} | ... | NN% | 控制比例 |
| {辅助线} | ... | NN% | 增强信任/案例 |

## 四、90 天行动路线图（三阶段）

### 第一阶段：定位验证期（第 1-30 天）——验证受众假设，建立初步认知
| 周次 | 动作 | 产出 | 验收标准 |
|------|------|------|---------|
| 第 1 周 | 定位语打磨 + 对外简介更新 + 个人故事梳理 | ... | ... |
| 第 2 周 | 首批 3 篇主方向内容试发 | ... | ... |
| 第 3 周 | 反馈收集 + 受众画像验证 | ... | 回收≥N 份有效调研，确认目标人群占比 |
| 第 4 周 | 首月复盘 + 方向调整 | ... | 复盘报告 + 下月日历 |

**第一阶段关键指标**：粉丝/阅读/分享率/目标人群占比（写具体可量化目标）

### 第二阶段：内容积累期（第 31-60 天）——建立品牌认知，启动社群
- 每周 2-3 篇主方向内容，建立合集
- 规划第一个低价产品（大纲 + 试水）
- 启动社群/种子用户运营

**关键指标**：合集篇数、付费试水收入、社群人数

### 第三阶段：变现启动期（第 61-90 天）——验证付费模型，建立飞轮
- 第一个付费产品完稿发布
- 体系化产品规划 + 试录
- 90 天总复盘 + 下季度 OKR

**关键指标**：产品销量、收入、课程预约、月收入目标

## 五、风险与应对表

| 风险 | 概率 | 影响 | 应对策略 |
|------|------|------|---------|
| {受众验证失败} | 中 | 高 | 第 1 个月密切盯数据，达不到就及时调整主辅 |
| {外部环境变化（技术迭代等）} | 中 | 中 | 内容从「怎么用」升级为「怎么设计/怎么管理复杂度」 |
| {竞争者快速跟进} | 中 | 中 | 加速积累，6 个月内建立品牌认知和内容壁垒 |
| {自身表达能力不足} | 中 | 中 | 前 3 个月打磨，「外行朋友能否看懂」自检 + 目标人群试读 |
| {产出量不足} | 高 | 中 | 用 AI 提升产出效率，建素材库/模板降低创作成本 |
| {变现过快引发反感} | 低 | 高 | 严格遵循「前期不以变现为目标」，免费建信任 |

## 六、成功的定义（90 天后验收）

给 5 条可量化验收标准（品牌认知/内容资产/受众验证/变现验证/增长趋势），并写明「若未达到，需诚实复盘是方向、内容、表达还是运营问题」。

## 输出模板

```markdown
## 一、多方向对比矩阵（8 维表 + 综合评分）
## 二、明确推荐（主方向 = X + Y，理由 N 条，不推荐方向及原因）
## 三、内容/投入占比建议（表格 + 关键转变说明）
## 四、90 天行动路线图（三阶段，每阶段周次/动作/产出/验收 + 关键指标）
## 五、风险与应对（概率/影响/策略表）
## 六、成功的定义（5 条量化标准 + 未达成的复盘指引）
```

## 常见坑
1. 只推荐不比较（必须有矩阵，且给「为什么不选其他」）
2. 路线图没有验收标准（每个动作必须有可量化验收）
3. 风险表写「注意风险」没有应对策略（必须给策略）
4. 拍板后不再回溯（战略锚定后，所有执行都应回溯到该方向）
