# 行途表达逻辑（万粉结构 × 不装）

> 核心：**成熟博主从用户需求出发讲「你想听的」，新手站在自我视角讲「我想说的」。**
> 但万粉逻辑 ≠ 营销号。精髓是「说读者关心的话」，不是「用大词镇读者」。
> 本 skill 管**结构级表达逻辑**；`de-ai-flavor` 管词级 AI 味，两者互补不重叠。

## 一、先认「装」——这是红线（2026-09-20 boss 拍板）

行途定位是**一线 AI 工程化实践者**，不端着、不吹。流量方法论学歪了 = 学成营销号。

**表演词黑名单（行内人一眼假，标题/开头一律不用）**：
- 军事/政治大词：收编、碾压、吊打、绝杀、强制
- 营销号词：喂饱、炸裂、王炸、封神、吊打、碾压
- 戏剧化反差：没人当回事、终于官方…了（装成先知）

**不装的词感（大白话，像跟同事聊）**：
追上来了、我只写了一份、你也配一遍吗、踩了个坑、说白了、讲清楚

**自检口诀**：写完标题/开头，问一句——「**这话行内朋友刷到，会不会觉得我在装？**」会 → 重写。

## 二、万粉表达逻辑 6 点（结构层）

**1. 视角切换：我想说 → 你想听**
- 新手：我给 5 个 AI 工具写说明书（自我叙事）
- 成熟：你也每个工具配一遍规则吗？（对准读者的问题/痛点）
- 注意：是**正文对准读者的问题**，不是标题堆大词。保留实证画面感。

**2. 爆款本质是做数据（赞藏评）**
- 让用户觉得「这说的就是我」+ 有情绪波动
- 不写自嗨流水账，每段问「读者为什么要停下来」

**3. 信息密度：每一句都要推进**
- 要么给痛点解决方案，要么给干货结论
- 删废话、删铺垫、删"回顾过去"
- 对照 `de-ai-flavor` 删空泛形容词

**4. 开头两秒定生死——四公式（标题/开头段选用）**
| 公式 | 怎么用 | 例子（不装版） |
|---|---|---|
| 痛点前置 | 读者正烦的事 | 你是不是也每个 AI 工具配一遍规则 |
| 身份反差 | 预期之外的组合 | 社区土办法，官方现在读它 |
| 利益承诺 | 读者能得到什么 | 一份喂饱 5 个，省事 |
| 反常识 | 打破直觉 | 写多份反而更乱 |

**5. 挖掘用户需求三渠道（选题时用）**
- 同领域爆款的评论区（读者在追问什么）
- 粉丝私信/提问（真实痛点）
- 近期低粉爆款（什么新角度在起量）

**6. 植入个人故事：关注 = 对人的期待感**
- 不是内容有用就够，读者关注的是"这个人"
- 自然融入自己的经历/踩坑/数字，不硬编
- 行途护城河：本地会话引文、真实项目数字、敢押的立场

## 三、标题自检流程（写标题时跑）

1. **过「装」红线**：有没有表演词黑名单里的词？有 → 删
2. **视角**：是"我想说"还是"你想听"？纯自我叙事 → 往读者问题挪半步
3. **四公式**：贴了哪个？一个都不贴 → 重写
4. **实证画面**：有没有具体的人/事/数字？纯观点 → 加画面
5. **SEO**：前 13 字含核心词（PUB-001），专有名词 ≤2 个（PUB-014-补）

## 四、与其他 skill 的分工

- `de-ai-flavor`：词级 AI 味（空泛形容词/套话）→ 本 skill 不管词，管结构
- `mp-title-collision-rename`：撞题核查 + 换题执行 → 本 skill 管"怎么起"，那个管"撞了怎么换"
- `writing-guidelines`：单篇文风规范 → 本 skill 管表达逻辑层
