## 一、格式元素清点脚本（泛化，可直接跑）

```python
# 用法：python3 清点脚本 <正文MD_1> [正文MD_2 ...]（系列级多篇时逐篇输出，并排成「元素×篇目矩阵」进报告）
# 关键词按本号正文习惯配置，新元素出现时在 elems 补一行（如「我是谁」换措辞），不误报为 0
import re, sys

def inventory(path):
    s = open(path, encoding='utf-8').read()
    elems = [
        ("blockquote 一句话摘要(信源说明)", len(re.findall(r'^> ', s, re.M))),
        ("先说我是谁 独立段", s.count("先说我是谁")),
        ("目录块(编号列表)", 1 if re.search(r'目录：\s*\n+(?:\s*\n)*1\.', s) else 0),
        ("信息说明块(信源透明)", s.count("**信息说明**")),
        # 标签行：token 内允许空格（"AI Agent推荐"），禁句读；命中后仍人工复核（启发式）
        ("标签行(产品名罗列)", 1 if re.search(r'^(?:[^。\n]{1,20} / ){2,}[^。\n]{1,20}$', s, re.M) else 0),
        ("延伸阅读块", s.count("延伸阅读") + s.count("相关阅读")),
        ("合集状态块(含待发布)", 1 if re.search(r'待发布|已发布', s) and s.count("合集") >= 1 else 0),
        ("关于行途段", s.count("关于行途")),
        ("求赞句", len(re.findall(r'点赞|在看|星标', s))),  # 不收「转发」：正文常作动词、误报高
    ]
    print(f"== {path} ==")
    for name, n in elems:
        print(f"  {name}: {n}")
    body = re.sub(r'\s|[#*>`\[\]()!|-]', '', s)
    print("  字数(去空白符号):", len(body))
    print("  配图占位:", len(re.findall(r'【配图：', s)))
    # 目录条目数（目录：后跳空行、取连续编号行）——与「节数」分开报数，防与正文编号行双算虚高
    lines = s.split('\n')
    toc_n = 0
    try:
        di = next(i for i, l in enumerate(lines) if l.strip() == '目录：')
        j = di + 1
        while j < len(lines) and not re.match(r'^\d+[\.、] ', lines[j].strip()):
            j += 1  # 跳空行
        while j < len(lines) and re.match(r'^\d+[\.、] ', lines[j].strip()):
            toc_n += 1; j += 1
    except StopIteration:
        pass
    print("  目录条目:", toc_n)
    # ── 首屏公式合规检查（口径 SSoT：DESIGN.md §五，02:29 定版：摘要≤60字、在引子图前、目录在位）
    qm = re.search(r'^> (.+)$', s, re.M)   # 文首第一条 blockquote = 摘要块
    if qm:
        summary = qm.group(1).strip()
        print("  首屏摘要字数:", len(summary), "≤60:", len(summary) <= 60)
        img_after = re.search(r'【配图：|!\[', s[qm.end():])
        img_before = re.search(r'【配图：|!\[', s[:qm.start()])
        print("  摘要先于首张引子图:", bool(img_after) and not bool(img_before))
    else:
        print("  首屏摘要字数: 无 blockquote 摘要块 → 违规（定版要求文首独立摘要）")
    # 目录是否在位：看上方「目录条目」输出（>0 即在位）
    # ── 结构病灶附加项
    h2 = len(re.findall(r'^## ', s, re.M))
    num_lines = len(re.findall(r'^\d+[\.、] .+$', s, re.M))  # 编号行总数（含目录条目与正文清单）
    print("  h2 二级标题数:", h2, "｜ 编号行数(含目录):", num_lines)
    if h2 == 0 and num_lines - toc_n > 2:
        print("  ⚠ 病灶提示：h2=0 且目录外仍有独立编号行 → 目录与节标题可能渲染同形（AGENT-03 01:23 h2 修复轮同源），并入报告；修渲染归 mp-prepublish-draft-verify")

for p in sys.argv[1:]:
    inventory(p)
```

**注意坑**（首案与换稿轮实测）：

- 目录块检测必须先跳过空行——`目录：` 与首条之间有空行，直接判 `目录：\n\n1\.` 或 `di+1` 会得到「目录条目 0」假阴性（AGENT-03 09-16 凌晨踩过）。
- blockquote 计数不区分文首摘要块与正文会话引语：引语是**人设痕迹要保留**，摘要块是定版首屏件——命中多时人工看行内容再入表。
- 节标题若写成 `1. xxx` 编号行而非 `## `，md2wechat 会渲成与目录无差的普通列表项（**目录与节标题渲染同形**，也是一种结构病灶）；该缺陷修渲染归 `mp-prepublish-draft-verify`，评估时 grep h2 数注明即可。
- 标签行正则只作启发式，命中后人工看一眼是否误伤正文内的并列短语。

## 二、双参照系特征对照表

| 维度 | 机构媒体支（APPSO/机器之心/量子位） | 强人设个人号支（半佛/差评/卡兹克） | 行途冷启动含义 |
|---|---|---|---|
| 自我呈现 | 无「我是谁」，品牌替作者说话 | 满篇是「我」：口头禅、自嘲、踩坑、立场押注 | 人设痕迹=信任资产，**加** |
| 结构容器 | 编辑部排版，无目录/标签行/引用块摘要 | 同样无 Markdown 结构痕迹 | 结构痕迹=写作者脚手架，**减或换形态** |
| 篇幅 | 2000–3500 字为主 | 跨度大，长文也少用编号目录 | 目录是篇幅的症状非格式偏好 |
| 信源透明 | 图注来源规范（「图｜Tom's Guide」）、文末引用 | 引文随手但格式野 | **学机构一处：外部图必注来源**；信息说明块保留 |
| 干净感的来源 | 编辑部流程 + 品牌沉淀 | 品牌沉淀 + 语感 | 都不是格式选择，不可平移到 51 粉号 |

**两支共有的、真正可抄的**：无结构痕迹、图注规范、首段即钩子。
**两支共有而行途不该抄的**：无自我介绍（身份阶段未到）、无目录长文裸奔（篇幅未控下来）。
**机构号首屏无摘要块不可比**：它们无「信源透明」人设资产要承载；我方摘要承担信任功能，`DESIGN.md` §五 定版摘要在引子图前。

## 七、判定用语库

- 改造类：**「信息留、形态换」/「压成一句、独立段删」/「位置后移、精简为两句」**（注意：「并进首段一句」对摘要块已作废，仅可用于我是谁段）
- 删类：**「纯 Markdown 习惯残留」/「搜一搜不认这个容器」/「暴露库存/手动产出冗余，平台功能已自动展示」**
- 保留类：**「信任资产/人设收口」/「完读率拐杖（篇幅症状，非格式偏好）」/「差异化资产，机构没有也不需要有」**
- 定版类：**「保留·定版默认（指针 DESIGN.md §五）——不逐轮重评，只查违规」**
- 红线句模板：**「只换形态不丢信息」**——任何「删」判定前必须先确认信息在正文他处存在，否则改判「搬」。
