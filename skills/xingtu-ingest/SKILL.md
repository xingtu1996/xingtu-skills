# 素材入库（xingtu-ingest）

> 定位：用户说"入库"即触发——把任意内容**分析价值 → 归类 → 落盘 → 登记索引**，成为可复用的行途素材资产。
> 来源：session-sediment xingtu 版 + 素材库既有格式（黄金会话萃取/素材卡/选题池）实践沉淀。

## 触发条件

- 用户说：入库 / 收入素材库 / 存到素材库 / 记一下这条素材 / 把这个收进选题池 / 分析并入库
- 用户粘贴：文本、链接、对话记录、想法、截图描述、AI 分析结果

## 核心流程（一句话：先读内容 → 判价值 → 定落点 → 落盘 → 登记）

### Step 1: 读取与理解内容
- 读取用户提供的内容（文本/链接抓取/对话/截图 OCR）
- 若为链接：按链接类型抓取正文（元宝链接用 `batch_fetch_yuanbao.py`；其他用 web fetch）
- 提炼 1 句话核心 + 3-5 个要点

### Step 2: 价值分级（判定后决定落点）

| 级别 | 标记 | 判定标准 | 落点 |
|------|------|----------|------|
| **黄金级** | 🥇 GOLDEN | 独家一手实践/观点，低同质化，可独立成稿 | 素材卡（完整方法论） |
| **关键级** | 🔴 KEY | 强证据力的硬事实/数据/可复现步骤 | 素材卡（evidence 锚点） |
| **重点级** | 🟡 FOCUS | 重要方法论/框架/对比维度 | 素材卡（方法论类） |
| **高知级** | 🟢 INSIGHT | 认知升级型金句/知识点 | 金句库 + 可做短内容 |

### Step 3: 定落点（按内容类型）

| 内容类型 | 落点路径 | 文件命名 |
|----------|---------|---------|
| 通用素材/观点/方法论 | `素材库/素材卡_{主题}_{日期}.md` | 主题用 2-5 字核心词 |
| 选题 | `xingtu-vault/02_内容仓库 (Content Hub)/01_灵感与选题池/2026-选题池.md` | 追加行 |
| 高价值对话/会话萃取 | `素材库/黄金会话萃取_{日期}.md` | 当日合并或新建 |
| 元宝内容 | `xingtu-vault/02_内容仓库 (Content Hub)/06_元宝对话挖掘/` | 元宝文章_{标题}_{token}.md |
| 重要节点 | `xingtu-vault/02_内容仓库 (Content Hub)/AI进化时间线与内容体系/00_时间线主索引.md` | 追加 |

### Step 4: 生成素材卡内容（模板）

```markdown
# 素材卡 · {主题}（{日期}）

> 级别：{🥇/🔴/🟡/🟢} · 来源：{来源} · 入库时间：{date}

## 一句话核心
{一句话}

## 要点
- {要点1}
- {要点2}

## 可复用角度
- 成稿方向 / 素材用途

## 关联
- [[相关素材]] · 后续动作
```

### Step 5: 落盘 + 登记
- 创建素材卡文件（追加式，不覆盖已有）
- 若当日已有 `黄金会话萃取_{日期}.md`，追加而非覆盖
- 在素材库维护一份 `素材库/素材库索引.md`（若不存在则创建），登记新卡一行：`- [素材卡_主题_日期](文件) — 一句话摘要`

### Step 6: 输出入库报告

```
## 入库完成
- 级别：🥇 GOLDEN / 🔴 KEY / 🟡 FOCUS / 🟢 INSIGHT
- 落点：{路径}
- 核心：{一句话}
- 可复用：{成稿方向/用途}
```

## 铁律

1. **先分析后入库**：先判价值定级别，不无脑追加
2. **追加式不覆盖**：同日已有文件则续写
3. **命名规范**：`素材卡_{主题}_{日期}.md`，日期 `YYYY-MM-DD`
4. **索引必登记**：入卡即登记到素材库索引
5. **脱敏**：涉及当前雇主/薪资/入职年限/隐私按用户偏好模糊化
6. **诚实标注**：无法判级或来源不明时标注"待核实"，不夸大价值
