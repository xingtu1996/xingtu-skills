# AI 协作偏好自我进化闭环（xingtu-collab-evolution-loop）

> 通用方法论。源自 2026-08-28 boss 把"复盘/反哺/沉淀/调研方法"抽象成可复用方法论。
> 适用任何"人带 AI 长期协作、需让 AI 学人偏好"的场景：内容创作 / 代码协作 / 调研 SOP / 团队规范 / 个人知识管理飞轮 / 跨项目偏好迁移。
> 配套 SSoT：`rules/RULES.md` 的 METHOD-001~003。内容场景的实例化见 `xingtu-content-craft` skill。

## 0 · 触发与自检（开工第一件事）
- 触发词：复盘 / 沉淀 / 调研 / 方法论 / 偏好 / 把经验变成规则 / 少犯错 / SSoT / 知识管理 / 通用方法。
- **四不防错自检（任意命中即纠偏）**：
  - 调研是不是只靠记忆归纳、没挖本地会话真身？→ 否，必须多源交叉（云检索 / 本地 jsonl / 过程产物 / 记忆日志）。
  - 复盘是不是无出处总结（"我们偏好 X"但指不出原话/原文件）？→ 否，每条结论带原话时间戳或文件证据。
  - 沉淀是不是散在记忆里没汇成 SSoT？→ 否，必须编号铁律 + 严重度 + 人审可维护。
  - 反哺是不是只记不用（没落成自动约束）？→ 否，必须 skill 自动加载 + 开工自检。

## 1 · 四环工作流（按序执行，闭环）

### 环 1 · 调研取证（Research）
- **多源交叉，不轻信单一记忆源**。列全所有可能来源：
  ① 云端会话检索（`conversation_search`）② 本地会话转录（`~/.workbuddy/projects/.../*.jsonl`）③ 过程产物（过程稿 / 脚本 / 看板 / README）④ 记忆日志（`.workbuddy/memory/`）。
- **关键防错**：云端检索返回 0 ≠ 无会话；本项目历史会话优先挖本地 `*.jsonl`（用 `tools/session_preference_miner.py` 抽 boss 原话）。
- **产出**：原始证据清单（带来源标注）。

### 环 2 · 复盘归因（Review）
- **带原话/原产物出处，拒绝无出处的归纳式摘要**。每条偏好/规则都要能指回"哪句话（时间戳）/ 哪个文件说的"。
- **关键防错**：抽象总结若无出处，先回头补取证；逐句对照（如「去 AI 味 5 改 2 留」）比一句话归纳更有价值。
- **产出**：「为什么这样改」证据链 + 归因结论。

### 环 3 · 沉淀 SSoT（Codify）
- **编号铁律 + 严重度，人审可维护**。分散记忆 → 单一事实源（`rules/RULES.md` 索引或独立方法论文档）。
- **关键防错**：分散记忆 ≠ SSoT；必须汇总为人能审、能改、带严重度的清单，否则下次又得重挖。
- **产出**：RULES 编号条目 / 方法论文档 / 看板。

### 环 4 · 反哺约束（Enforce）
- **落成自动加载的 skill + 开工自检 + 主动提示**，让"规则"真正拦在 AI 犯错之前。
- **关键防错**：只记不用 = 白沉淀；必须变成"下次自动带、先过自检"的约束。
- **产出**：项目级 skill（`.workbuddy/skills/`）+ 使用约定挂钩（如 RULES.md 第 10 条）。

> **闭环飞轮**：偏好（人）→ 规则（SSoT）→ 约束（skill 自动加载）→ 下次协作少踩坑 → 再取证复盘，越跑越准。前两步决定"沉淀得对不对"，后两步决定"沉淀用不用得上"。

## 2 · 通用迁移清单（拔掉"公众号创作"外壳后直接套）
- **代码协作偏好沉淀**：把"封面迭代/去 AI 味"换成"重构偏好/命名规范"，四环不变。
- **调研 SOP**：调研取证环 = 列全信源交叉验证；复盘环 = 标注每结论来源与验证程度（BUL-003）。
- **团队规范**：沉淀环 = 团队 RULES；反哺环 = CI / PR 模板 / 代码评审 checklist 自动拦。
- **个人知识管理飞轮**：本地 jsonl + 记忆 = 第二大脑；定期跑四环把碎片变 SSoT。
- **跨项目偏好迁移**：把 SSoT 抽成"跨项目级"skill（放 `~/.workbuddy/skills/`），新项目直接加载。

## 3 · 工具速查
- 会话偏好挖掘：`tools/session_preference_miner.py`（挖本地 `*.jsonl` 抽 boss 原话）
- 创作铁律总装（四环在内容场景的实例化）：`xingtu-content-craft` skill + `rules/RULES.md` PUB-010~020
- 防弹依据链：BUL-001~005
- 深度沉淀实证：`outputs/公众号内容创作偏好深度沉淀_2026-08-28.html`

## 4 · 红线
- 调研环不得伪造来源；复盘环不得无出处下结论；沉淀环不得只存在记忆里不汇 SSoT；反哺环不得只写文档不落地自动约束。
