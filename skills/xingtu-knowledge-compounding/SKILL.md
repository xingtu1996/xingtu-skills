## 触发时机

- 成稿/出片前要判断「这篇对谁有用、值不值得做」——价值导向自检
- 想把做过的内容（视频/文章/会话）沉淀成可复用知识资产
- 内容生产方法论咨询（复利、知识卡片、信息vs知识）

## 一、核心骨架：三次认知升维

| 升维前（旧逻辑） | 升维后（新逻辑） | 关键判断 |
|---|---|---|
| 第一次 | 追爆款：设钩子、留人、等人刷到 | **供需关系**：做可搜索的内容，满足长期真实需求 | 爆款三天就灭，需求不会消失；内容要具备「可搜索」的持久价值 |
| 第二次 | 表现自己：我想讲什么 | **产品思维**：这条能解决谁的问题 | 对别人有用，变现是自然的事（「一个对社会有用的人，不可能穷」） |
| 第三次 | 拍完就废：下次从零开始 | **资产思维**：每条沉淀为知识卡片，入库叠加 | 爆款是烟花，爆过就没了；资产是滚雪球，越滚越大 |

金句点睛（可作正文钩子/封面副标）：
- 「爆款是烟花，爆过就没了。资产是滚雪球，越滚越大。」
- 「一个对社会有用的人，不可能穷。」

## 二、拍前自检三问（选题筛选，写/拍前必过）

1. **这条对谁有帮助？**（目标读者/用户是谁，痛点是真需求还是自嗨）
2. **他什么场景下能用？**（落地场景是否具体，能不能「搜到就能用」）
3. **你愿不愿意把它当成资产留下来？**（做完了会不会沉淀——不值得沉淀的选题要怀疑价值）

三问全过 → 值得做；任一问含糊 → 先补清楚再开工，别带着模糊价值开始消耗轮次。

## 三、产品四要素公式（内容结构，写/拍时套用）

从「我想讲什么」切换到「他需要什么」，按四要素组织内容：

1. **这条讲什么**（一句话说清主题/结论——放在最前，别让人猜）
2. **你是不是遇到了这个问题**（共情锚点，把读者拉进来）
3. **背后原因是什么**（机理/根因，给「为什么」）
4. **具体该怎么做**（可操作步骤，有动作、有命令、有数字，不能只讲道理）

> 与行途正文结构 SSoT 对照：先说结论 → 逐层展开（概念界定→原因→意义→举措）→ 行动钩子——同一套「价值导向先行」在不同载体的投影。

## 四、拍后资产化：知识卡片提取指令（可直接复制的 Prompt）

把原文（逐字稿/文章/会话记录）丢给 AI + 下面这段指令，自动产出结构化卡片：

```
你是一个知识管理专家。请把下面这段内容提取成一张标准化的知识卡片，要求包含以下四个模块：
1. 【解决什么问题】这条内容针对的具体问题是什么？谁会遇到？
2. 【背后机理】这个问题背后的原理/原因是什么？
3. 【具体方案】可操作的步骤或方法是什么？（要有动作，不能只讲道理）
4. 【适用场景】在什么情况下可以调用这张卡片？
5. 【一句话钩子】（可选）这条内容最值得转述/复用的那一句是什么？
同时做一次逻辑自检：内容逻辑是否自洽？有没有跳跃或漏洞？
如果有逻辑不通或方案缺失的地方，请明确指出。
---
[在这里粘贴你的视频逐字稿或文章内容]
```

**卡片审核四问**（原文标准，四问全过才入库）：
1. 逻辑通不通？
2. 解决什么问题？
3. 机理是什么？
4. 有没有具体方案？

四问全过 → 存进知识系统 → 下一条在此基础上叠加（越做越顺）。审核不过 → 退回补全，不带病入库（防知识库变垃圾堆）。

## 六、使用纪律

1. **价值导向先行**：任何内容开工前先过三问，不过三问不写正文（与 boss「文章要表达什么/给读者什么价值」同源，见 mp-publish-sop Step 1b 背景）。
2. **不造词**：三问/四要素/四问来自姜胡说原话提炼，引用时保持原意，不发明新概念（与「未实测不假装用过」同纪律）。
3. **沉淀要留痕**：用本技能产出知识卡片/方法论调整后，回写 CHANGELOG（`--tool doubao`）与素材库索引。
4. **一图一隐喻**：若需配图表达本方法论，走 `concept-anchor-figure`（如「烟花 vs 雪球」就是现成隐喻）。

## 七、表达结构检查表（Winston《How to Speak》，boss 2026-10-15 提供）

> 来源：MIT AI 实验室前主任 Patrick Winston 公开课《How to Speak》核心技巧（素材卡：`THU包/07_作者素材/知识卡片实验/Winston_表达结构知识卡片_v1.md`）。价值导向（姜胡说三问）管「对谁有用」，表达结构（Winston）管「怎么讲清楚」。

### 演讲质量公式

`演讲质量 = 掌握的知识 K × 练习次数 P + 天赋 T`——天赋占比极小，全靠学习和练习（对内容创作同样成立：写得多、改得多，比天赋重要）。

### 开场：赋能承诺（不用笑话）

- 反对一上来讲笑话冷场；用「赋能承诺」——告诉观众/读者接下来能学到新东西，让 TA 留下来。
- 与行途「导读给预期 / 这篇能给你什么」同构：开头先把价值亮出来。

### 四大表达技巧（写/讲通用）

| 技巧 | 做法 | 行途落地示例 |
|---|---|---|
| 循环三次 | 重要的事说三遍（开头/中间/结尾） | 「先说结论 → 正文论证 → 一句话记住」重复强调 |
| 建围栏 | 讲清「我的想法 vs 别人的想法」边界 | THU §3 两条路线对比、「我讲的 vs 你没见过的」 |
| 设置标志点 | 给走神的人提供跟上节点 | h2 小标题 + 目录 + 每节首句给结论 |
| 提出问题 | 提问难度适中，等答案 ≤7 秒 | 正文反问钩子（如「你要的到底是『它记得』还是『它想得对』」） |

### 内容包装五要素（5S）

Symbol（视觉符号，如封面图）→ Slogan（概括短语/标题金句）→ Surprise（反直觉惊喜/钩子）→ Salient idea（突出核心观点）→ Story（讲自己做到的故事，真实经历）。

### 收尾禁忌（行途文末 CTA 纪律同源）

- 禁「THE END」「详情请见…」「长串合作者名单」「欢迎提问」式收尾；**禁「谢谢聆听」**（居高临下）。
- 正确收尾：感谢观众提问 + 表达期待下次再来 → 对应行途文末「谢谢你看我的文章，下篇见」（用户侧感谢，非讲台致谢）。

### 沟通能力优先级

温教授排序：演讲能力 > 写作能力 > 思想质量——缺乏沟通能力步入社会如士兵不带武器上战场。对行途：内容生产就是在练演讲/写作/思想的复利。

## 八、知识卡片入库流程（P0/WED/THU 三包实测沉淀，v1.3.0）

> §四 管「怎么出卡」，本节管「出卡之后怎么落、怎么登记、怎么留痕」。2026-10-15 以 P0 / WED / THU(+Winston) 三包实测跑通，写成可复用 SOP。**缺登记 = 卡存在但检索不到，等于没入库**。

### 五步 SOP

1. **出卡**：按 §四 提取指令产出卡片草稿 → 过审核四问。四问全过才继续；不过退回补全，不带病入库。
2. **落盘**：放发布包 `07_作者素材/知识卡片实验/<文章名>_知识卡片_v1.md`。三包实测路径（均在 vault `03_运营工具箱 (Operations Toolkit)/发布包归档_2026-10/` 下）：
   - `P0_AI的记忆只有30天_20261011/07_作者素材/知识卡片实验/P0_知识卡片_v1.md`
   - `WED_说不清需求AI就替你乱跑_20261014/07_作者素材/知识卡片实验/WED_知识卡片_v1.md`
   - `THU_AI开始记得住了_20261015/07_作者素材/知识卡片实验/THU_知识卡片_v1.md`（同目录含 Winston 补卡）
3. **登记素材库索引**：在 `素材库/素材库索引.md` 末尾「知识卡片」小节登记新卡（一行：链接 + 一句话摘要 + 主题 tag）；历史遗留未登记的旧卡同处补登。
4. **核查已发布包索引**：发布后核对 `02_内容仓库 (Content Hub)/07_发布与归档/03_已发布/已发布包索引.md`——路径必须指向 vault 归档位，迁移前旧路径要修正（见坑位 K3）。
5. **CHANGELOG 留痕**：`python3 tools/changelog_append.py --type "🆕" --path "<卡片路径>" --desc "..." --tool doubao`。

### 卡片头部标注规范（照 P0/WED 卡头部四行引用块抄）

每张卡顶部固定四行 blockquote：

- **来源**：`<文章名>正文_vN（YYYY-MM-DD 已发布，wc -m N 字符，含 frontmatter/排版符号）`。字数口径 = `wc -m` 全字符数（含 frontmatter 与排版符号），与 P0（4,649）/WED（5,632）一致，不另算纯正文。
- **提取方式**：xingtu-knowledge-compounding §四「知识卡片提取指令」（四模块 + 一句话钩子 + 逻辑自检）。
- **审核**：四问全过 ✅（逻辑通 / 问题清 / 机理明 / 方案有动作）· 一致性 ✅（数字与正文逐节对齐，如「与正文 §1/§2/§6 逐字对齐」）。
- **标签**：主题 tag，`#AI记忆 #会话清理 #ClaudeCode` 风格（空格分隔、可叠加检索）。
