# 蓝海选题（Blue Ocean Strategy）

> - 含义：做内容/产品前，先判断市场是不是蓝海、人群多大、缺口在哪、该打谁
> - 核心机制：六步走——市场环境→人群量化→受众分层→缺口选题→方向锁定→路线图
> - 适用场景：新账号定位、内容方向选择、产品立项、副业可行性判断

## 提示词文本（直接复制使用）

```
请按「蓝海六步」帮我分析：「（我的方向/赛道/账号）」。

S1 明确意图：我要回答的核心问题是什么（市场是否蓝海？人群多大？缺口真实吗？该锁定哪个方向？）
S2 市场环境：规模 / 增速 / 竞争格局 / 增量还是存量 / 蓝海判断
S3 人群量化：从大池子到可付费人群的漏斗，每层大概多少人
S4 受众分层：人群分层金字塔，锁定核心目标层 + 画像
S5 缺口选题：竞品不覆盖什么？痛点排序？可打的选题/需求缺口清单
S6 方向锁定：多方向对比矩阵 + 推荐 + 90 天路线图 + 风险应对

数据纪律：每个数字标来源（硬数据 / 估算 / 推测），禁止编造。
```

## 用法示例

- 「按蓝海六步分析：我的 AI 工程化内容账号」→ 市场/人群/缺口/方向四件套
- 「按蓝海六步分析：这个副业方向值不值得做」→ 漏斗量化 + 方向推荐

## 使用技巧

- 关键产出是 S5 的「缺口清单」——竞品不覆盖的地方才是你的位置
- 推荐方向必须给「为什么不选其他」的对比，不做无依据单选
