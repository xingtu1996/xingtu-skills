# 个人 IP 冷启动操盘（Personal Brand Cold Start）

> - 含义：从零起一个自媒体/个人 IP 时，不让 AI 一上来就写文章，而是先把"基建—资产—选题—发布—变现"五层跑通最小闭环
> - 核心机制：工欲善其事——先统一各平台账号名/头像/简介/文件夹，再建素材库与选题清单，然后按"选题→形式→制作→发布"流水线小步快跑，MVP 先跑再迭代
> - 适用场景：打算做个人 IP/技术博主/副业账号但不知从何下手、资源已攒了一堆却乱、总想纠结命名而不动手

## 提示词文本（直接复制使用）

```
作为资深个人 IP 操盘手，帮我把这个号从 0 到 1 跑起来。我的背景和目标：【一句话说清你是谁、想对谁说话、靠什么变现，例如：做了 X 年技术，想给同样背景的人看 AI 工程化实践】。

按下面五层给我规划，每层先给 MVP（今天/本周能跑起来的最小版本），再给完整版，不要一上来就追求完美：

1. 基建层：各平台账号名/头像/一句话简介/背景图是否一致；每个平台一个专属文件夹，文件夹里再分「进行中/已发布/待复盘」
2. 资产层：盘点我现有的工作实践、项目、文章、聊天记录，哪些能直接变内容；建一个素材库表格（素材→可做什么选题→对应平台）
3. 选题层：选题清单按「受众痛点 × 我有独家经验」打分排序，先做 3 个本周能发的
4. 制作发布层：选题→内容形式→制作→发布，单平台单账号节奏建议，错峰发布；标明哪些内容必须脱敏（在职雇主/薪资/同事）
5. 变现层：这个阶段先不要想变现，先想清楚"我凭什么被记住"；列 3 种可能的远期变现路径，标注各自需要先积累什么

纪律：
- 小步快跑、分段提交、MVP 先完成再完美，不要等想清楚全局才动手
- 所有待办落成清单并 P0/P1/P2 分级，P0 是我今天就能做的
- 敏感信息（雇主、薪资、同事真名）一律模糊化，宁可不说也不瞎说
- 我的目标是建立个人影响力 + 知识沉淀，顺便变现；如果某一步明显偏离这个目标，直接提醒我
```

## 反模式（要避免的）

- **上来就写第一篇爆款**：账号名/头像/简介都没统一就发文，读者点进来看到"半成品门面"直接划走
- **一上来就规划 100 个选题**：没有 MVP，永远停在"准备阶段"；先跑通 3 篇再说
- **为命名纠结两周**：名字 80 分就行，先发出去再迭代，纠结命名是拖延的伪装
- **把变现当第一步**：0 粉阶段想怎么挣钱只会焦虑，先解决"凭什么被记住"
- **不分平台一刀切**：公众号/小红书/B站读者不同，同一篇通稿全平台同步是大忌

## 用法示例

- 「我做了 8 年后端，想做个 AI 提效的技术号」→ AI 先给五层 MVP 清单，你本周只做基建层 + 3 个选题
- 「素材攒了一硬盘但不知道怎么发」→ 第 2 层资产盘点直接用上
- 「我总在纠结账号叫啥」→ 提示词里"MVP 先跑"纪律就是治这个的

## 使用技巧

- 这是一个"启动器"，不是"一次问答"：跑完一次后，把待办清单存成 spec/看板，后续会话逐次推进
- 第 1 层基建别超过一周，做完立刻进第 3 层选题，别在装修上无限打磨
- 脱敏纪律单独跟 AI 强调一遍：在职做副业时，这一条比文风重要
- 与 media/blue-ocean-strategy 的顺序：先用那篇做蓝海分析、锁方向（市场多大、缺口在哪、打谁），再用本篇把"基建—资产—选题—发布—变现"五层 MVP 跑起来。一个想清楚再做，一个跑起来再说。
