# 本月复盘上月：从工作痕迹挖选题（Monthly Topic Retrospective）

> - 含义：每月花一小时，从上月真实做过的事里反推选题，而不是凭空想「这周写什么」
> - 核心机制：一手实践是普通人最难抄、最有差异化的素材；按四类型给选题分档，宁缺毋滥
> - 适用场景：个人 IP / 技术自媒体月度选题、内容创作者定期找素材、想把「做过的事」变成「能发的文章」

## 提示词文本（直接复制使用）

```
我是一个做内容的人，想从【上个月】真实做过的事里挖选题。请你帮我做一次月度选题复盘。

第一步·回溯来源：陪我从上月的痕迹里找「值得写的事」，来源按这个优先级：
1. 工作/项目里做的事、踩的坑、跑通的方法；
2. 我和 AI/工具的对话与复盘记录；
3. 我读过、试过、收藏过的素材；
4. 上月已发内容的数据和读者反馈（验证什么有效）；
5. 长期经历、能增加人设厚度的事。

第二步·四类型归类：把每条候选归到下面一类，并说清为什么——
- 踩坑复盘型：上个月踩了什么坑，别人也可能踩（「我把 X 搞砸了，原因是……」）；
- 方法沉淀型：上个月跑通了什么流程/方法（「我总结出 X 的 4 步法」）；
- 认知升级型：上个月想通了什么、纠正了什么旧观念（「我终于明白 X 和 Y 不是一回事」）；
- 工具实测型：上个月实测了什么工具/配置（「实测 X，真实账单/真实效果」）。

第三步·打分砍题：每个候选按四条打分（1-5）——有没有一手细节？普通人看得懂吗？有别人没有的差异点？是真实实践不是编的？3 分以下直接砍，宁可空一周也不硬凑。

第四步·输出一张选题表：候选 | 类型 | 一手细节（时间锚点+具体数字）| 读者能带走什么 | 差异化分 | 建议档位。

最后，挑分最高的 1-2 个，按下面这个复盘文结构给我一个写作骨架：
标题=时间锚点+反差；开头≤3行（一句话结论+时间锚点+能带走什么）；当时场景（真实细节）；翻车/卡住（真实代价，要有数字）；复盘拆解（根因+3-5 条可执行清单，找「不变的规律」）；（可选）第二次验证的数字对比；结尾给 3-5 条可带走的结论。
```

## 反模式（要避免的）

- **凭空想选题**：坐在那想「写什么好」，出来的都是别人写过的
- **写没有一手细节的**：没有真实时间锚点和数字，一眼就是编的，信任归零
- **硬凑数量**：为了不断更写 3 分以下的题，拉低账号整体水准
- **流水账**：只记「我做了 A 又做了 B」，不提炼「不变的规律」，读者带不走东西

## 用法示例

- 「按这个模板，帮我把上个月做的事过一遍，挖 4 个选题」→ 输出选题表 + 1 个写作骨架
- 「这个月没什么大事可写」→ 照本提示词从会话/素材/数据里翻，往往能翻出被忽略的坑

## 使用技巧

- 核心是「工作驱动」：你解决过的真实问题，就是别人正在搜的问题
- 工具会变、细节会过时，所以每篇要落到「不变的那条规律」，文章才历久弥新
- 上月已发内容的数据结论要回流到下月选题，形成飞轮
