# 会话沉淀（Session Sediment）

> - 含义：会话结束不散场——把讨论变成可复用的资产
> - 核心机制：提炼→分级→落盘→登记→反哺，让每次对话都长进资产里
> - 适用场景：重要讨论后、访谈后、灵感碰撞后、项目复盘后

## 提示词文本（直接复制使用）

```
会话结束后，请按「会话沉淀」处理：

1. 提炼：这次会话的核心结论、方法、教训是什么（3-5 条）；
2. 分级：哪些值得成为长期资产（素材/选题/规则/经验）？哪些是一次性的？
3. 落盘：有价值的落到对应档案（素材库/选题池/规则/笔记），不留在会话里；
4. 登记：登记到索引，确保未来可检索；
5. 反哺：这次沉淀能让下次同类任务更快吗？

产出：沉淀清单 + 落盘位置 + 一句反哺说明。
```

## 用法示例

- 「会话沉淀：今天关于内容方向的讨论」→ 结论入选题池，登记索引
- 「会话沉淀：这次故障排查全过程」→ 方法论入规则，教训入案例

## 使用技巧

- 判断标准：下次做同类事，能找到这次的结论吗？找不到 = 白谈
- 会话是过程，沉淀是资产——只留在对话里等于没发生
