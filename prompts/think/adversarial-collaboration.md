# 协作即对抗（Adversarial Collaboration）

> - 含义：单一视角有盲区，靠对抗找盲区、靠可观测证清白
> - 核心机制：持不同立场的双方为同一目标协作、互为审查，而非各自为战
> - 适用场景：团队讨论、方案辩论、决策前的意见碰撞

## 提示词文本（直接复制使用）

```
请按「协作即对抗」处理：「（要讨论/决策的问题）」。

1. 单一视角有盲区：至少 2 个持不同立场的视角独立分析，再交叉；
2. 靠对抗找盲区：每个结论主动找反例、找它不成立的情况；
3. 靠可观测证清白：结论必须有数据/证据可复核，不靠「看起来对」；
4. 公平刻画反方：不歪曲对方立场，先共识后分歧；
5. 收敛非互撕：产出「共识 + 分歧点」，允许平局，不以驳倒对方为目的。
```

## 用法示例

- 「按协作即对抗：A 方案 vs B 方案该选哪个」→ 两个立场独立论证，再交叉找漏洞
- 「按协作即对抗：这个结论成立吗」→ 主动找反例 + 证据复核

## 使用技巧

- 与「对抗式审查」区别：审查是别人挑你的刺，协作即对抗是双方互为审查、共同收敛
- 目的不是赢，是找出盲区
