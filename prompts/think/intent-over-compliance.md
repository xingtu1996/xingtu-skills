# 不机械执行（Intent over Compliance）

> - 含义：清单是候选不是命令，先懂为什么再执行
> - 核心机制：纪律性遵循 ≠ 盲从；判断权不可让渡，走流程 ≠ 做对了
> - 适用场景：对照检查清单、走流程、执行 SOP 时防止「照单全抄的合规表演」

## 提示词文本（直接复制使用）

```
请按「不机械执行」原则处理：「（检查清单/流程/任务）」。

要求：
1. 先懂为什么：每一条为什么存在？不查会出什么错？不理解就追问；
2. 清单是候选不是命令：逐条判断是否适用，不适用要说明理由；
3. 不为合规而合规：走了流程 ≠ 做对了，产出质量才是目的；
4. 判断权不让人：AI 给建议、给分析，决策由人做，不盲从；
5. 结果复核：勾了 ≠ 对，关键项留下证据链。
```

## 反模式（要避免的）

- **照单全抄**：逐项勾掉却不解意图——「我不懂含义，但我勾了」
- **为合规而合规**：以「走了流程」免责，产出对错没人管
- **清单当护身符**：勾满即安心，不质疑清单本身是否过时

## 用法示例

- 「按不机械执行原则过一遍：发布检查清单」→ 逐条说清为什么查、不查会出什么错
- 「按不机械执行原则处理：这条规范里哪些适用、哪些不适用」→ 裁剪必须说明依据
- 「按不机械执行原则分析：为什么这个流程在走过场」→ 找出「为合规而合规」的环节

## 使用技巧

- 每次勾选前问：「我理解这条为什么存在吗？」
- 裁剪清单（跳过/新增）必须写理由，没理由的裁剪等于盲从
- 最考验判断力的地方（关键路径、门禁点）人亲自看，其余交给工具
