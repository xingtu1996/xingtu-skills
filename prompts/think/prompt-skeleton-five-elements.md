# 写好提示词的五要素骨架（Prompt Five-Element Skeleton）

> - 含义：写一段能让 AI 一次做对的提示词，套「角色/目标/输入/输出/铁律」五件，少留猜测空间
> - 核心机制：AI 做错事，八成不是模型笨，而是输入没给全——Garbage In Garbage Out；五要素齐了，返工率骤降
> - 适用场景：任何要让 AI 干活的提示词，尤其是开发、排查、写方案这类容易返工的任务

## 提示词文本（直接复制使用）

```
帮我把下面这个任务写成一段高质量提示词，按五要素补齐，缺哪项先标「待确认」让我补：

我的任务大意：【一句话说你要干什么】

五要素检查并补全：
1. 角色：你让 AI 以什么身份干（如：后端架构师 / 排查专家 / 审稿人）——不写会立场漂移；
2. 目标：最终交付什么，用「作为…我想…以便…」说清，必须可验收；
3. 输入：给齐锚点（从哪开始/哪个 Ticket）、澄清（有歧义先问）、坐标（文件:行号 / 单号 / 链接）、约定（分支/分支/commit/目录）——不写 AI 就广撒网乱找；
4. 输出格式：产出物长什么样、放哪、用什么结构（如：问题清单=位置|问题|修法）——不写格式会漂；
5. 铁律：哪些不许动、哪些红线（如：不另起炉灶、不改无关代码、结论必须带来源）。

最后自检：五要素齐吗？我自己读一遍，有没有「AI 可能误解成两件事」的地方？有就先改清楚再发。
```

## 反模式（要避免的）

- **只说「帮我做个 XX」**：没角色没验收标准，AI 自由发挥，做完返工
- **缺坐标**：让 AI 在整个代码库里自己找入口，一通乱读，又慢又偏
- **没写「不做什么」**：AI 顺手把不相关的也改了，越界
- **要素写了一半**：五要素凑不齐五件就发，等于赌 AI 猜对

## 用法示例

- 「按五要素，把『给这个接口加个导出功能』写成可直接用的提示词」→ AI 先补出待确认项，你答完再出终稿
- 写完一段提示词总觉得效果不稳定 → 用本提示词反查自己漏了哪一要素

## 使用技巧

- 一个快速自检：把提示词念给一个新人听，他能不能不问你就开干？不能就补输入要素
- 复杂任务先落一个最小 Spec 再让 AI 动手，比来回对话省 token 也省时间
- 待确认项清零之前不开工，是省返工的第一道闸
- 与 think-slim-rules-for-new-model 的区别：本篇是**写新提示词**的加法骨架（五要素补齐）；那篇是**换模型后给旧规则做减法**（删过时/重复/过度约束）。
