# 聚焦精进（Focus & Iterative Mastery）

> - 含义：护城河建立前不扩张——把手头之事做到极致（小、专、精、快）
> - 核心机制：探索→发现→迭代→纠错闭环，护城河未建不接新机会
> - 适用场景：个人成长、产品/工具开发、内容方向、创业项目

## 提示词文本（直接复制使用）

```
请按「聚焦精进」原则评估：「（我当前做的事/要做的扩张）」。

1. 护城河建了吗：当下事的极致标准、可复用资产（方法/模板/知识）沉淀了吗？没有 → 不接新机会；
2. 聚焦还是发散：新需求是现有能力的自然深化，还是开新摊子？开新摊 → 挂起，先补当下；
3. 小专精快做到了吗：最小闭环 + 可复用 + 扛过对抗 + 快速交付，缺哪条补哪条；
4. 循环状态：我处在 探索/发现/迭代/纠错 哪一环？下一步动作是什么？

结论：现在该聚焦做什么、明确不做什么。
```

## 用法示例

- 「按聚焦精进评估：我该不该同时开三个内容方向」→ 护城河判断 + 明确不做什么
- 「按聚焦精进评估：这个新功能要不要现在做」→ 深化还是新摊子判断

## 使用技巧

- 扩张前的三问：护城河建了吗？聚焦还是发散？小专精快做到了吗？
- 「明确不做什么」和「做什么」一样重要
