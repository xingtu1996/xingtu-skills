# 双向钢人论证（Steelman Argument）

> - 含义：当你有两个选项犹豫不决时，让 AI 把两个方向都"最有力地"论证一遍，再互相挑战
> - 核心机制：区别于 grill me（帮你想清楚问题），钢人论证是在问题已清楚、选择未定时的决策工具——先把双方都推到最强，再找关键分歧
> - 适用场景：二选一决策、选项犹豫、拍板前的最后论证

## 提示词文本（直接复制使用）

```
我需要做的决定是：【写清问题、两个选项、目标和现实约束】。 先别急着回答，也别默认我已经把问题想清楚。请先做一次双向钢人论证： 1. 用最完整、有力的方式，重述我真正需要做出的选择；2. 分别给出支持两个方向的最强理由、适用条件、最大收益、最大风险，以及最难回答的反对意见；3. 找出双方真正的分歧、最可能改变结论的关键变量，以及还需要补充的信息；4. 只问我一个最可能改变结论的问题。 等我回答以后，再给出明确判断、理由、适用条件和下一步行动。
```

## 反模式（要避免的）

- **稻草人攻击**：只挑一方弱处打，没有把双方推到最强再比
- **默认问题已清楚**：没重述"真正需要做出的选择"就开答
- **一次问一堆问题**：钢人论证只问一个最可能改变结论的问题，多问就变成问卷

## 用法示例

- 「我需要做的决定是：公众号主文放晚 20:15 还是早 8:00，目标是阅读+完读，约束是…」
- 「我需要做的决定是：自研 vs 采购某工具，目标是…约束是预算和时间」

## 使用技巧

- 回答它那"一个关键问题"后再要结论，别跳过——这正是决策的关键变量
- 适合 boss 拍板场景：先论证后选择，答案可留痕
