# 事故复盘五问（Postmortem Five Questions）

> - 含义：出事后问五句，从「为什么会发生」一路问到「下次怎么防」
> - 核心机制：根因→检测→测试→影响→预防，五层都挖透才算复盘完
> - 适用场景：线上事故、生产问题、重大 bug、任何「不该发生却发生了」的事

## 提示词文本（直接复制使用）

```
请按「事故复盘五问」复盘：「（这次事故/线上问题）」。

1. 为什么会发生？（根因，不是表面现象）
2. 为什么当时没发现？（检测机制为什么没拦住）
3. 为什么测试没覆盖？（用例缺口在哪）
4. 影响面是什么？（除了已知的，还有什么被影响）
5. 下次怎么防？（落到检查/测试/门禁，不靠记忆）

每个问题必须给具体答案，不许说「应该/可能」；最后一问必须可执行。
```

## 用法示例

- 「按事故复盘五问复盘：凌晨的订单积压」→ 根因/检测/测试/影响/预防五层各给具体答案
- 「按事故复盘五问复盘：这个数据不一致问题」→ 重点挖「为什么测试没覆盖」

## 使用技巧

- 第三问最扎心也最值钱：「为什么测试没覆盖」答案通常是「没人想过这个场景」
- 复盘产出必须有一条落到「下次自动拦截」，否则等于没复盘
