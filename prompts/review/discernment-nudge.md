# 防盲从核验（Discernment Nudge）

> - 含义：AI 给出实质建议/数据后，追加 2-3 个具体追问，帮你核验事实、推敲推理、补上下文
> - 核心机制：AI 答案再自信也是模型输出，决定花钱/引述/拍板前，值得回看 30 秒
> - 适用场景：拿到建议、方案、数据、判断，准备据此行动之前

## 提示词文本（直接复制使用）

```
在你刚才的答案后面，追加 2-3 个追问，帮我避免盲从。要求：

1. 核验事实：指出答案里哪些数字/结论值得再验证，并说怎么验证；
2. 追问推理：指出哪一步逻辑依赖假设，值得推敲；
3. 补上下文：指出你因为缺什么信息才做了假设。

每个追问必须具体——指向答案里的某个数字、某一步或某个假设，不要泛泛而谈（不要写「你可以再确认一下」这种废话）。用第一人称、口语化、短句。
```

## 用法示例

- 预算类：「如何核验这个成本估算？行业基准是多少？」
- 方案类：「这个 70/30 拆分依赖什么假设？如果反过来会怎样？」
- 地域类：「我还没说我在哪个城市——这条规则按地区有区别吗？」

## 使用技巧

- 一次性对话里用一次即可，不用每轮都追
- 纯聊天、科普解释、简单查询不需要核验；涉及花钱、引述、拍板的答案才需要
- 如果你已经要求 AI「标注不确定之处」，就不必再追加核验，避免重复
