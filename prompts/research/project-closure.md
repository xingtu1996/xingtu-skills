# 项目结项（Project Closure）

> - 含义：结项 = 交付证据 + 复盘沉淀 + 知识归档，不是一句「做完了」
> - 核心机制：八段报告，让收尾可验收、可追溯、可复用
> - 适用场景：项目结束、阶段收尾、向相关方汇报

## 提示词文本（直接复制使用）

```
请按「项目结项」八段帮我收尾：「（项目）」。

① 项目概览：名称/周期/目标/范围
② 交付清单：交付物 + 验收人 + 状态
③ 验收证据：每项验收怎么验证的 + 链接/记录
④ 量化成果：数字带来源（工期/规模/覆盖率/缺陷率）
⑤ 复盘教训：做对/踩坑（提炼成下次可用的规则）
⑥ 资产沉淀：归档位置（可检索）
⑦ 风险遗留：未决项 + 责任人 + 跟进计划（不掩盖）
⑧ 责任交接：各模块负责人 + 交接物 + 后续入口
```

## 用法示例

- 「按项目结项八段收尾：这个功能上线了」→ 交付证据 + 教训 + 交接
- 「按项目结项八段：月度阶段小结」→ 每段一行，可追溯

## 使用技巧

- 反模式三连：只报喜无量化、只交付不沉淀、遗留责任悬空
- 第八段最重要：责任到人，收尾不烂尾
