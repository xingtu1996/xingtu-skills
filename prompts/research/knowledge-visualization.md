# 知识可视化（Knowledge Visualization）

> - 含义：同一份知识两种形态——文本真相源 + 可视化看板
> - 核心机制：文本管真相（Git 可 diff、AI 可读），看板管扫视（一眼看懂）
> - 适用场景：知识库建设、清单管理、数据汇总、任何「记下来还要看得懂」的内容

## 提示词文本（直接复制使用）

```
请把「（这份知识/清单/数据）」做成「文本真相源 + 可视化看板」双形态：

1. 文本真相源：内容只记一遍（Markdown），是唯一权威；
2. 可视化看板：从真相源生成 HTML 看板（单文件、双击可开、零依赖）；
3. 单一事实源：改内容只改文本，看板同步生成，禁止两处手写；
4. 看板要素：聚合卡片 + 筛选 + 搜索，一眼能扫；
5. 反 AI 味：系统字体、语义色、无花哨渐变。

输出：文本源 + 看板文件 + 一句使用说明。
```

## 用法示例

- 「把这份素材清单做成双形态」→ README 真相源 + 可筛选看板
- 「把这次调研结果做成双形态」→ 文本结论 + 对比看板

## 使用技巧

- 核心防「双写漂移」：同一份数据只允许在一个地方改
- 看板的价值是「扫视」——聚合、筛选、搜索，不是美观
