# 今日工作日报模板（Daily Report Digest）

> - 含义：按项目分组列"今日完成 ✅ + 明日计划"，不流水账，让领导/协作方一眼看到进展
> - 核心机制：日报的价值不是记流水，是让别人 30 秒知道你干了什么、明天干啥、卡在哪
> - 适用场景：团队日报、周报、站会、向上汇报

## 提示词文本（直接复制使用）

```
按以下格式整理今日工作（根据实际情况增删项）：

今日工作
【项目/系统 A】
1. 【事项 1：做了什么 + 结果 ✅】
2. 【事项 2：做了什么 + 结果 ✅】
   ○ 【关键决策/会议结论，带责任人】
3. 【事项 3】

【项目/系统 B】
4. 【跨项目支持：做了什么】

【AI 协作/基建】（如有）
5. 【沉淀了什么 SOP / 工具 / 规范】

明日工作
1. 【明天要做的第一件事】
2. 【第二件】
3. 【需要对齐/依赖的事】

相关截图/链接（如有）
```

## 反模式（要避免的）

- **流水账**："上午开会、下午写代码、晚上部署"——领导不关心你时间怎么花
- **只写做了什么不写结果**："改了 bug"不如"修了 N 个 bug 并部署验证 ✅"
- **明日计划太泛**："继续推进"不如"完成 X 链路 SIT 验证 + 剩余用例补齐"
- **跨项目混着写**：按项目分组，不然别人找自己关心的项目要翻半天

## 用法示例

- 一天同时推进主功能 + 跨团队支持 + AI 基建：三块分组写
- 遇到决策点：写"与产品会议确认：A 规则维持现状、B 8/25 上线，测试需闭环"

## 使用技巧

- 每条带 ✅ 表示闭环，不带 ✅ 就是进行中
- 决策/会议结论单独列 ○，这是最有信息量的部分
- 明日计划按优先级排序，第一条是明天第一件事
- 有阻塞写在明日计划里，让别人知道怎么帮你
- 与 research/session-daily-report 的区别：那篇是**AI 读会话记录自动生成**日报（主题→产出→卡点→下一步）；本篇是**人按格式整理**的结构化日报模板（按项目分组+✅闭环+决策○单列+明日 P0）。会话记录现成用那篇，自己凭记忆报进展用本篇。
