# 能力分层（Capability Tiers）

> - 含义：能力决定用哪层工具、给 AI 多少自主——匹配 > 求高
> - 核心机制：四维定位（熟练度/工具层/自主度/组织成熟度），只升一维
> - 适用场景：选 AI 工具、定 AI 工作方式、团队 AI 化路径

## 提示词文本（直接复制使用）

```
请按「能力分层」帮我定位：「（我/我的团队）」。

四维定位，匹配 > 求高：
1. 开发熟练度：新手 / 中级 / 高级 / 专家？
2. 工具层：L0 裸聊 → L1 低代码 → L2 IDE → L3 CLI → L4 自建平台，我该用哪层？
3. AI 自主度：人全干 → AI辅助 → AI驱动 → AI主导，我适合哪档？
4. 组织成熟度：个人试用 / 有复用资产 / 机械强制 / 委派 / 分布式？

结论：当前在哪 + 下一步只升一维 + 对应的工具和做法。
```

## 用法示例

- 「按能力分层定位：我是新手，该用什么 AI 工具」→ 低层起步 + 模板兑底
- 「按能力分层定位：我的团队卡在哪」→ 四维诊断 + 下一步

## 使用技巧

- 新手硬上高层工具 = 门槛高不可控；专家被低层限制 = 没效率
- 反模式：全员套同一层、跳级进阶（几乎必然返工）
