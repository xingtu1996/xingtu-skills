# 本地轮回（Local Loop）

> - 含义：一个想法从冒头到沉淀的完整小循环，每环留痕
> - 核心机制：想法→调研→澄清→立项→落地→实战→登记，7 环闭环
> - 适用场景：新想法推进、任务执行、个人知识管理

## 提示词文本（直接复制使用）

```
请按「本地轮回」推进：「（想法/任务）」。

7 环节，每环留痕，小步循环：
1. 想法：记录想法/问题；
2. 调研：查已有方案/资料；
3. 澄清：确认目标/边界/验收；
4. 立项：落成可执行计划；
5. 落地：执行/编码/实现；
6. 实战：跑通/验证/用起来；
7. 登记：沉淀结论/教训到档案，登记索引。

每环结束输出一句话进展 + 落盘位置；下一环从上一环结论继续。
```

## 用法示例

- 「按本地轮回推进：做一个小工具」→ 想法→调研→澄清→…→登记，全程留痕
- 「按本地轮回推进：这个学习目标」→ 每环沉淀，学完即资产

## 使用技巧

- 核心是「每环留痕」——不留痕的循环是原地打转
- 第七环登记最关键：沉淀进档案，下次同类任务直接复用
