# 方案选型（Solution Research）

> - 含义：调研→对比→选型→决策，多源聚合，不闭门造车
> - 核心机制：先查本地有没有，再多源搜外部，决策必须落地方案
> - 适用场景：技术选型、工具选择、竞品调研、方向评估

## 提示词文本（直接复制使用）

```
请按「方案选型」帮我做调研：「（要选什么型）」。

1. 先查已有：仓库/笔记里有没有相关调研或实现？命中即停；
2. 多源对比：候选方案 ≥2 家，每家给官方链接 + 核心特性；
3. 对比表：特性 / 成本 / 风险 / 适用性 横向对比；
4. 溯源：每条关键发现带来源，数字必须标出处，无来源标「待查」；
5. 区分状态：已验证 / 待验证 / 推测 分开标；
6. 决策：推荐哪个 + 理由 + 为什么不选其他。
```

## 用法示例

- 「按方案选型调研：接口测试工具选哪个」→ 三款对比表 + 来源 + 推荐
- 「按方案选型调研：自建还是买现成」→ 成本/维护/风险对比 + 决策

## 使用技巧

- 只看一家就拍板是最贵的决策方式
- 数字（价格/星数/用量）必须带来源，否则标「待查」
