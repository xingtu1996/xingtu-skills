# 最小实验替代空想（Minimal Experiment）

> - 含义：当纸上谈兵无法让决策更清晰时，设计一个低成本、可逆、短周期的最小实验来获取现实反馈
> - 核心机制：决策背后往往有可验证的假设；先验最可能改变结论的那个假设，用现实数据替代空想
> - 适用场景：纠结于选择/想法、需要迈出第一步、用数据验证方向

## 提示词文本（直接复制使用）

```
我正在纠结的是：【填写你的选择或想法】。 请先找出这个决定背后最需要验证的3个假设，再选出最可能改变最终结论的那一个。 围绕这个假设，帮我设计一个低成本、可逆、能在【7天或你能接受的周期】内完成的最小实验。 请写清：1. 具体要做什么；2. 需要投入多少时间和资源；3. 观察什么指标；4. 什么结果支持继续；5. 什么结果提醒我停止；6. 实验结束后能获得什么新信息。 最后告诉我，明天就能开始的第一个动作是什么。
```

## 反模式（要避免的）

- **实验太大**：超过周期/成本不可逆，就不是"最小实验"
- **假设没排序**：没先选出"最可能改变结论"的假设就设计实验
- **没有停止信号**：只有"支持继续"没有"提醒停止"，容易沉没成本

## 用法示例

- 「我正在纠结的是：要不要日更公众号」→ 验"日更是否带来阅读增长"假设，7 天实验 + 指标 + 停止线
- 「我正在纠结的是：要不要做视频号」→ 验"内容是否适合口播"假设，先试 3 条

## 使用技巧

- "明天就能开始的第一个动作"是破除拖延的关键
- 实验结束的"新信息"要能反过来更新决策，不是为做而做
