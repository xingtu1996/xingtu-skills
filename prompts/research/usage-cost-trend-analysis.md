# 用量成本多期趋势（Usage Cost Trend）

> - 含义：把 AI 工具的用量数据按固定周期（如每两周）滚一期，做成"环比 + 一句话归因"的趋势表，而不是只给一个快照
> - 核心机制：单期数字看不出趋势，多期对比才看得出"人变多了还是用深了、钱涨了是涨价还是用量涨"
> - 适用场景：汇报 AI 平台推广情况、算 ROI、向老板证明渗透率/活跃度、做成本预警

## 提示词文本（直接复制使用）

```
请把我们 AI 平台的用量数据做成"多期趋势"汇报，不是单期快照。

【每期固定指标】（按固定周期切，如每两周一期）
- 在用用户数 / 在册用户数（注册）
- 总请求数、总 Token 数
- 总费用、次均费用
- 每请求平均 Token

【输出要求】
1. 每期一行，按时间排：在用 / 在册 / 请求 / 总 Token / 总费用 / 次均；
2. 加一列"环比变化"，每个变化后面跟一句人话归因——
   例：请求数 -19%（两周对两周可比）；每请求 Token +31%（深度任务变多）；总费用 +185%（主力切到贵模型）；
3. 做一版拆分视角：按区域/团队拆，给出人数、请求数、人均请求、次均费用，并指出哪个区域是主力、哪个是深度用户；
4. 指出异常：哪个指标突然跳变（如次均费用翻倍），说明可能原因，需要数据侧进一步核实。

要求：所有数字从后台 API/数据库取，不要估；口径写清楚（可识别口径 vs 全量）；别只报总数，把没用起来的人也列出来。
```

## 反模式

- 只放最新一期的数字——老板不知道你是涨了还是跌了
- 把"总费用涨了"直接写成坏事——可能是因为大家用得更深了，要拆到"是涨价还是用量涨"
- 只列活跃用户，把没使用的人藏起来——推广汇报要连"没渗透的"一起看
- 数字口径前后不一致（这期按注册、下期按活跃），环比就废了
- 凭感觉写"渗透率上升"——没有上期分母，不算

## 用法示例

> 场景：双周汇报 AI 工具在团队里的推广成效。
>
> 四期趋势表：在用 69→62→67→71，在册 107→107→109→128；第四期总费用跳到 ¥14,876、次均 ¥0.0697。
> 环比归因：在用 +4、在册 +19（注册在涨）；请求 -19%（两周可比）；每请求 Token +31%（大家开始跑深度任务）；总费用 +185%（主力模型换成更贵的档，不是用量涨）。
> 区域拆分：某区域渗透率 76% 是主力；另一个区域人均请求全平台第一，是深度用户。

## 使用技巧

- 固定周期、固定指标、固定口径——这三件事必须每期不变，趋势才有意义
- "次均费用"比"总费用"更能说明问题：总费用涨可能是人多了，次均涨才是模型选型/缓存策略的信号
- 把"没用起来的人"单列一栏给推广负责人看——这是下一步拉新的靶子
- 数字宁可从 API 取真实值，也别手填；手填一次，后面每期都得背这个口径
