# 会话日报（Session Daily Report）

> - 含义：让 AI 分析会话记录，30 秒能读完的日报
> - 核心机制：主题→产出→卡点→下一步，四段式，要点化
> - 适用场景：每天收工时、周报前、多项目并行时

## 提示词文本（直接复制使用）

```
请分析「（今天/最近）」的会话记录，帮我写一份日报：

1. 今天聚焦了什么（主题 + 目标）
2. 产出了什么（交付物 + 状态）
3. 卡点是什么（阻塞 + 需要谁/什么）
4. 明天的建议（下一步做什么）

格式：要点式，每项 1-3 行，人能 30 秒读完。
```

## 用法示例

- 「分析今天我跟 AI 的历史会话，帮我写个日报」→ 四段式要点日报
- 「分析这周五个项目的会话，各出一行进度」→ 多项目周报

## 使用技巧

- 每天收工时跑一次，第二天开场不用回忆
- 日报本身也是素材：攒一个月就是月度复盘
