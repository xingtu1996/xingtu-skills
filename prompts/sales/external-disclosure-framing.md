# 对外口径禁忌词映射（External Disclosure Framing）

> - 含义：把"我们在修自己产品"这类对内事实，重构成客户视角的交付分类，并用一张「禁忌词 → 安全讲法」表兜住所有对外话术
> - 核心机制：客户一旦听出"我花钱是在替你补你自己的短板"，报价性质就崩了；所以对内成本口径和对外讲法必须物理隔离，提前把敏感词全部翻译成中性交付项
> - 适用场景：售前报价、客户沟通、对外文档/话术里，涉及"既有产品还要补课/补强/停摆"等不利事实时

## 提示词文本（直接复制使用）

```
我要准备一份对外话术/文档，背后的事实是【把真实情况写在这里，例如：产品某块能力停摆过几年、对接新渠道需要补课、历史代码要补强】。这些话绝对不能原样对客户说。

请帮我做两件事：
1. 列出这份对外话术里必须出现的交付分类（例如：产品版权买断 + 渠道对接实施 + 集成测试 + 运维），所有工作项都要能落进这几个筐里，不许出现"完善/补课/停摆/补强/修 bug"这类暴露我方短板的词；
2. 做一张「禁忌词 → 安全讲法」对照表：左边是对内会说的真实词，右边是对外可以讲的等价说法，确保客户听不出"花我的钱修你们的产品"。

规则：
- 对外只讲客户买到什么、我方交付什么，不讲我方历史欠账；
- 凡是"我方产品本应自带却要客户买单"的部分，要么并入买断价不单独拆出来，要么翻译成"对接适配/实施服务"；
- 表格要能直接贴进销售话术里照着念。
```

## 反模式（要避免的）

- **对内口径直接外溢**：把"补课/补强/停摆三年"写进给客户的文档，等于告诉客户"你在帮我们还债"
- **单独拆出"产品完善费"**：这一项一出现，报价性质立刻从"买产品"变成"替厂商补产品"
- **没有对照表靠临场发挥**：销售记不住规则，必须落成一张表，照念即可

## 用法示例

- 对内事实"渠道同步代码要从老项目搬过来，40 人天" → 对外"渠道对接实施"
- 对内事实"产品有 200 人天的功能要补" → 对外并入产品买断价，不单独列
- 对内事实"我们这产品停摆了三年没维护" → 对外"渠道对接实施"，绝不提停摆

## 使用技巧

- 先定"对外只讲哪几个交付筐"，再让所有工作项往里塞，塞不进去的就是漏嘴风险点
- 这张表对内保密（属于披露边界），对外只发"安全讲法"那一列
- 新销售入职直接发这张表，比讲十遍规则管用
- 与 write/external-material-sensitize 的区别：本篇是**售前报价**特化——把"产品停摆/补课"等对内事实重构成客户交付分类、做"禁忌词→安全讲法"对照表；那篇是通用对外材料过稿（脱敏+软化承诺+数据口径）。报价性质敏感的话术用本篇。
