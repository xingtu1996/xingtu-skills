# 省 token 检查（Token Saver）

> - 含义：把「不用推理的活」从模型手里拿回来
> - 核心机制：八层检查（需求/检索/输入/输出/生成/提示词/配置）逐层找最亏的
> - 适用场景：AI 使用习惯优化、工作流瘦身、提示词审查

## 提示词文本（直接复制使用）

```
请按「省 token」原则审查：「（我的工作流/提示词/使用习惯）」。

逐层检查，每层给结论+补法：
1. 需求层：先想清楚要什么再动手吗？有规格/清单吗？
2. 检索层：用检索代替翻文件了吗？还在无脑盲搜吗？
3. 输入层：能引用就不粘全文？能过滤就先滤？
4. 输出层：要求精简/要点式了吗？还是在读散文？
5. 生成层：只写需要的吗？还是顺手写一堆将来可能用的？
6. 提示词层：立规矩→给反例→兜底自问，三段式吗？
7. 配置层：常驻内容精简吗？频繁切模型吗？

结论：哪层最亏？先补哪层？
```

## 用法示例

- 「按省 token 原则审查：我的日常提问习惯」→ 找出最亏的 2 层，给具体改法
- 「按省 token 原则审查：这条提示词」→ 精简掉不必要的内容

## 使用技巧

- 金句：省 token 是顺便，把「不必要」剥掉才是真本事
- 最亏的三层通常是：没想清楚就开工（需求）、翻文件不检索（检索）、输出不设格式（输出）
