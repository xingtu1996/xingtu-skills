# 喂 Agent（Feed the Agent）

> - 含义：把任务变成「喂 Agent 的任务包」，让它自跑自纠错，而不是人盯人带娃
> - 核心机制：足上下文 + 清规格 + 准流程，一次讲清，等待时间外包
> - 适用场景：给 AI 派复杂任务、多 Agent 并行、需要 AI 自主完成的工作

## 提示词文本（直接复制使用）

```
请把「（任务）」变成「喂 Agent 的任务包」：

1. 足上下文：背景/目标/现状/约束，结构化写清，不让我猜；
2. 清规格：验收标准——怎么算做完？可验证（能编译/能跑/过哪些测试）？
3. 准流程：执行步骤 + 检查项 + 门禁；
4. 自纠错：遇到编译/测试失败的排查指引；
5. 输出：任务包全文，可直接发给 AI Agent 自跑。
```

## 反模式（带娃，要避免）

- **每步盯**：频繁纠正，单线陪跑
- **标准口头**：零散标准，改完再挑
- **串行等待**：人盯着，等一步走一步

## 用法示例

- 「把重构这个模块变成喂 Agent 的任务包」→ 上下文/规格/流程/自纠错四件套
- 「把整理这份数据变成喂 Agent 的任务包」→ 验收标准写清，AI 自跑

## 使用技巧

- 喂养三要素：足上下文（少返工）、清规格（少吵架）、准流程（自纠错）
- 解放出来的人手，开多个 Agent 并行，是 10 倍效率的来源
