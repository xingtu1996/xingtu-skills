# ELI5 — 把我当成五岁小孩重新解释

> - 含义：Explain Like I'm 5，意为「把我当成五岁小孩重新解释一遍」
> - 核心机制：默认使用者完全没有专业背景 → 先帮你看懂全局 → 再逐步解释关键细节
> - 适用场景：理解复杂代码、产品逻辑、商业模式等「看不懂的问题」

## 提示词文本（直接复制使用）

```
请用 ELI5 的方式向我解释：「（这里填入你要理解的主题）」。

要求：
1. 默认我完全没有相关专业背景，禁止直接抛术语；
2. 先用一两句话给我一个全局概览——它是什么、解决什么问题、为什么重要，让我先看懂全局；
3. 再逐步拆解关键细节，每一步都从已解释过的概念出发，不跳步；
4. 必须用生活化的类比和例子把抽象概念具象化；
5. 每引入一个新术语，先用一句大白话解释它，再继续使用；
6. 最后用一段话总结，确认我真的懂了。
```

## 用法示例

- 「请用 ELI5 的方式向我解释：区块链」
- 「请用 ELI5 的方式向我解释：这段代码里的依赖注入是什么意思」
- 「请用 ELI5 的方式向我解释：我们公司这套积分体系的商业逻辑」

## 使用技巧

- 理解新领域的第一步：先用 ELI5 建立全局框架，再深入细节
- 想深挖某部分时追问：「再用 ELI5 深挖一下刚才提到的 X 部分」
- 想验证是否真懂：让 AI 把「五岁小孩」换成「要向你汇报的老板」，再解释一遍
