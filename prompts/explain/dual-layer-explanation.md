# 双层解释法（Dual-Layer Explanation）

> - 含义：同一个概念分别用「小白版 + 专业版」两层解释，避免"好像懂了"
> - 核心机制：单层类比容易停在"听懂"的错觉，双层解释补上专业机制，并把两层对应起来
> - 适用场景：学习新概念/技术名词、Vibe Coding 遇到看不懂的库、写"先人话后专业"的内容

## 提示词文本（直接复制使用）

```
我想学习的是：【填写概念或问题】。 请分两层解释： 第一层，小白版。用生活化的语言和一个具体例子，让完全没有基础的人也能听懂。 第二层，专业版。使用准确术语，讲清核心机制、适用边界和常见误解。 最后请整理出：1. 列出小白说法与专业术语的对应关系；2. 我最容易理解错的地方；3. 3个用于检查我是否真正理解的问题。
```

## 反模式（要避免的）

- **只有小白版**：类比记住了，真实机制还是一团雾
- **只有专业版**：术语堆砌，无法建立直觉
- **两层割裂**：小白说法和专业术语对不上号，学了等于没学

## 用法示例

- 「我想学习的是：数据库索引」→ 小白版"书的目录" + 专业版 B+ 树/聚簇索引/回表
- 「我想学习的是：RAG（检索增强生成）」→ 小白版"考试开卷翻书" + 专业版 embedding/召回/重排

## 使用技巧

- 最后 3 个自检问题用来验证是否真懂；答不上就再问一轮
- 写作时可直接复用：先小白版做开头（生活化类比），再专业版展开（机制+边界）
