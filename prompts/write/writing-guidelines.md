# 写作规范审查（Writing Guidelines Review）

> - 含义：按规范逐条审稿，输出「位置+问题+改法」
> - 核心机制：先定规范（或给维度），再逐条对照，只报问题不重写
> - 适用场景：文章定稿前、文档评审、对外内容把关

## 提示词文本（直接复制使用）

```
请审查「（文章/文档）」是否符合写作规范：

1. 结构：段落有序、重点前置？
2. 语言：有人话感吗？有 AI 腔/黑话/废话吗？
3. 数字：有来源吗？口径清晰吗？
4. 语气：像真人写的吗？目标读者能懂吗？
5. 格式：层级/列表/引用规范吗？

输出：位置 + 问题 + 建议改法，一条一行；只报问题不重写（除非我要求）；最后给一句话小结。
```

## 用法示例

- 「按写作规范审查：这篇文章能发吗」→ 逐条对照，位置精确到段落
- 「按写作规范审查：这份对外文档」→ 语言/数字/格式三维把关

## 使用技巧

- 与「去 AI 味」分工：去味是改写，审查是挑问题；先审查后去味
- 数字必须有来源，无来源标「待查」，这是硬规矩
