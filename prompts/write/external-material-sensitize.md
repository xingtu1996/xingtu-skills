# 对外材料脱敏与口径校准（External Material Sensitize）

> - 含义：把给客户/合作伙伴的材料过一遍——删掉内部信息、把硬话变软、把不可承诺的话说成"需求侧输入"，既专业又留余地
> - 核心机制：对外材料 ≠ 内部方案；多写一句内部信息，就多一分被动；口径委婉不是软弱，是不把话说死
> - 适用场景：给客户发技术方案/容量建议/交付物前、给合作伙伴回邮件前、任何要出公司门的文档

## 提示词文本（直接复制使用）

```
请帮我校准这份【对外/给客户】材料，做三件事：

1. 脱敏——删掉或泛化：
   - 内部报价、销售口径、合同金额、人天成本；
   - 内部组织架构、同事姓名、内部系统名、内部协作扯皮过程；
   - 任何"一旦上报就难追加""这个我们不承诺"之类对我方不利、或逼客户表态的硬话。

2. 口径软化——把"承诺句"改成"留余地句"：
   例如把"我们保证能支撑 X"改成"这是我方需求侧输入，不是对贵方部署的承诺；能不能到、怎么调，等贵方部署后实测数据回来，两家对着调"。
   原则：是合作伙伴，不是甲方乙方对赌，话说清楚就好，别生硬。

3. 数据可论证——凡是写出去的数字：
   - 统计范围、统计口径要一句话讲清楚；
   - 关键单位/技术术语给非技术读者也能看懂的解释；
   - 我方内部访问细节、内部 ID 不出现。

要求：去 AI 味；普世普惠，别假设对方有专业背景；改完我能直接发出去。
```

## 反模式

- 把内部方案的措辞直接复制给客户——"这是我们不承诺的""一旦上报确认后续难以追加资源"这种话绝对不能出现在对外稿
- 写具体报价/产品版权费/年运维——那是销售才知道的口径，技术交付文档里只写客观工作情况
- 数字写得很猛，但不交代统计口径——客户问"你这数怎么算的"就答不上来
- 为了显得专业堆术语——对外材料要让对方"看得懂、挑不出刺"，不是炫技
- 把内部群里"谁推的锅、谁没担责"的情绪带进材料

## 用法示例

> 场景：要把一份"私有化部署容量建议"发给合作方技术团队。
>
> 原稿写："若需要，我可整理一份统计口径给你们核对"——这种"给不给你看着办"的话太傲慢，删掉。
> 原稿写："这是对你们部署的容量承诺"——太硬，改成："本表是我方需求侧输入，我们只负责把'想用多猛'讲清楚，能不能到等你们实测回数据，两家对着调。"
> 同时把内部人员名单、内部账号归属、内部访问 ID 全部抹掉，关键技术术语补一句白话解释。

## 使用技巧

- 改之前先问自己："这句话客户看到会怎么想？"——凡是让对方觉得被将了一军、或暴露我方底牌的，就改
- "需求侧输入 vs 我方承诺"这个句式是万能缓冲——把"保证"换成"输入"，责任边界立刻清晰
- 对外材料宁可少写一行，也别多写一句内部信息；删错了顶多再补，写错了收不回
- 如果材料要截图进汇报/发群，先过一遍隐私扫描：真名、手机号、邮箱、内部 URL、token 一律不能出现
- 与 sales/external-disclosure-framing 的区别：那篇是**售前报价场景**的"对内不利事实→对外交付分类+禁忌词对照表"；本篇是**通用对外材料**的过稿（删内部信息、承诺句软化、数字讲口径）。售前报价话术用那篇，一般客户邮件/技术方案过稿用本篇。
