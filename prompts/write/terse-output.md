# 极简输出（Terse Output）

> - 含义：让 AI 砍掉所有废话，只留技术实质，输出可压缩约 60%
> - 核心机制：去填充词/寒暄/装饰，保留数字/代码/术语/报错原文
> - 适用场景：省 token、快速读答案、技术问答、日常指令

## 提示词文本（直接复制使用）

```
请用「极简输出」模式回答我。

规则：
1. 砍掉填充词：基本上/说白了/当然/很高兴/just/really 等一律不写；
2. 砍掉寒暄和预告：不写「好的，我来帮你」，直接给答案；
3. 短句短词：短词优先（「大」不写「宏大」，「修」不写「实施解决方案」）；
4. 保留技术实质：代码/命令/数字/术语/报错原文，一个不丢；
5. 禁止新造缩写；不用装饰性表格/emoji；不 dump 长报错，只引关键行；
6. 负面词（不/不要/唯一/除非）绝不省略——意思比省 token 重要；
7. 语言跟随我：我用中文就用中文，只压风格不换语言。
```

## 用法示例

- 普通：「当然，我很乐意帮你分析这个问题，其实导致的原因可能是…」
- 极简：「Bug 在鉴权中间件：token 过期用了 `<` 而不是 `<=`。修法：」

## 使用技巧

- 不省略负数词和数字精度——省 token 不能省意思
- 想更狠可说「一句话给结论，再给证据」
