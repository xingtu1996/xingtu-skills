# 反矫饰文风（Remove Mannered / Flourish Prose）

> - 含义：把 AI 用隐喻和修辞堆出来的「文艺腔」，改回直接、朴素、就事论事的表述
> - 核心机制：矫饰文风用花哨的说法替代直接陈述——本该说「一个值得调整的参数」，它写成「一个值得拧动的旋钮」；问题不在用词难，在于绕
> - 适用场景：AI 写出来的东西读起来发闷、句子越来越长、爱用比喻撑场面、技术文档/总结要干净直接

## 提示词文本（直接复制使用）

```
把下面这段文字里的矫饰文风删掉，改回直接陈述：「（粘贴原文）」

什么叫矫饰文风：它用隐喻、排比、华丽修辞替代本该直接说的事实。比如本该说「一个值得调整的参数」，矫饰的写法是「一个值得拧动的旋钮」；本该说「提升了速度」，写成「按下了加速的引擎」。

规则：
1. 先删：把所有「拧动的旋钮、按下引擎、开启新篇章」这类替代说法，换回它实际指代的东西；
2. 再说清：一句话只讲一个事实，主语+动作+对象，别拐弯；
3. 保留：真正必要的比喻、行业通用术语、关键数字和结论，不要删成干巴巴；
4. 追求的是「直接」，不是「简单」——准确比花哨重要。

改完通读一遍：每一句能不能用最朴素的话说清楚？能，就不要修辞。
```

## 反模式（要避免的）

- **矫枉过正**：把必要的类比也删光，技术文档变得没人味、难读
- **分不清 AI 味和矫饰**：「赋能/抓手/闭环」那套是黑话，「拧动的旋钮」这类是修辞——两者都该删，但别只删一种
- **为短而短**：把一个必要的复杂概念硬砍成短句，丢了信息

## 用法示例

- 「按这条把这篇总结的文风过一遍，别整得跟宣传稿似的」
- AI 生成的复盘里全是「按下加速键、撬动新范式」→ 改回「把某配置从 A 改成 B，速度提升 X」
- 和「去 AI 味」一起用：一个删黑话，一个删修辞，两遍下来就干净了

## 使用技巧

- 先把要反对的「坏味道」定义清楚（像本提示词那样给个对照例子），AI 才知道删什么
- 想省事也可以只用一句：「Please remove all mannered prose. / 删掉所有矫饰的修辞。」
- 适合放在系统提示里长期生效：让 AI 默认就写得朴素直接
- 与 write/de-ai-flavor 互补：那篇删**黑话/AI 腔词**（赋能/抓手/闭环）；本篇删**矫饰修辞/隐喻**（拧动的旋钮、按下引擎）。两遍下来文风才干净。
